# Python v0.1.0 — 固定32手構成の安定版

状態：2026-10-26、v0.1.0 の品質・配布検査を完了。[GitHubの公開版](https://github.com/iwmn-9/reflex-persona-core/releases/tag/v0.1.0)。11月3日目標・7日期限に対し、検証を省かず前倒しで到達した。

登録40組は26改善・9同等・5悪化、四分野すべての平均が改善した。全10,240実判断と公開資料からの再監査が一致し、元の採用条件をすべて満たした。[判断と既知の限界](adoption.json)、[全結果](../long_horizon/REPORT.md)。

既存の人格・欲求・実経験の学習・相手予測・再計画を `FixedHorizonOwner` の一つの入口へまとめる。採用済みの実装を配布用に接続し、新しい判断機構やゲーム別補正は追加しない。

安定版として扱うのは、明示した構成の `decide → resolve → checkpoint/restored` 契約と、それを支える既存の判断・学習・予測の接続。`reflex` 配下の研究用モジュールすべてや任意の部品の組合せを安定版に昇格させるものではない。

構成は `horizon=32, seeds=(701,702,703), recovery_cache=64`。人格、目的、公開ルール、合法手、結果の意味、累積価値の換算はゲーム側が宣言する。世界の実状態と乱数はゲーム側が保持し、実際に観測した結果だけを `resolve()` へ返す。公開モデル内の予測で得た経験は、実際の本人の経験に混ざらない。

保存は実結果を反映し終えた境界で行う。世界・実乱数と本人を一緒に保存し、同じルールと `model_id`、同じ人格・予測器・探索設定で復元する。破損、違うモデルや設定、未反映の判断の保存は拒否する。予測を完了できなかった時に、即時判断へ黙って置き換えることはしない。

インストール、推奨設定、ゲーム側の責任、失敗時の扱いは [安定版の導入ガイド](../../docs/STABLE_INTEGRATION.md) を入口とする。[ホスト例](../../examples/stable_host.py) は研究用runnerを使わず単独で動く。`tools/verify_stable_host.py` はリポジトリ外・別プロセスで公開wheelを読み、途中保存と終局保存からの復元を検査する。リリース時の `tools/verify_receding_package.py` による検査も保全する。

対応確認は Windows/Linux、Python 3.12/3.13。NumPy が必須。LLM、GPU、Colab、外部APIは不要。このv0.1.0配布物の長期判断はPythonで提供する。後続のmainには判断・実経験・保存復元を持つRust統合を追加したが、公開wheelへ遡って混ぜていない。Rust連携は [別の統合契約と検証](../rust_port/owned/REPORT.md) を参照。

残る限界は、有限の読みと世界予測の誤り、条件・人格による個別の悪化、重い探索の費用。評価は限定された四つの持続世界であり、未知のゲーム、人間水準、楽しさ、全NPCのリアルタイム実行を保証しない。ルール・結果のモデルを用意するゲーム側の負担も残る。

利用許諾は従来どおり未付与。公開版・配布物の作成によって、利用・改変・再配布の一般的な許可を新たに与えない。
