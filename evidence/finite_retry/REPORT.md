# 準備の終了時点に関する機構診断

状態: Pythonの隔離実験。安定版・Rust・進行中の元20実行には変更なし。採用候補の置換や独立40条件への進行はしていない。

既存の `PreparationChain(5, payout=14)` のH8診断は、元から失敗として残していた。通常判断は小利益を選び続ける一方、準備の反復候補は最初の5手で利益を得ても、その後の3手で未完了の次の準備へ費用を使う。そのため、準備を始める価値まで低く評価する。読みをH10へ延ばすと改善していたが、原因は先が短いことだけでなく、候補に準備を終える時点が足りないことにある。

今回の小さな差分は、既存の「通常判断」「全期間の反復」を残し、有限の時点で反復を終えて同じ本人の判断へ戻る候補を加えるもの。根だけ実行し、次の実観測後に再評価する方針は変えない。元の人格・欲求・学習・目的評価・世界・予測乱数を使い、ゲーム名や行動名から終了条件を与えない。既定値では追加候補なし。

まず固定の2手・4手という候補で、既知H8失敗の改善、不採算の準備の拒否、行動名を替えた同じ選択、元の予測経路と仮想本人の完全保持を確認した（3テスト、4.459秒）。これは単体の機構確認で、長期利益の実証ではない。

続いて、同じ既知課題の128手を、2人格×収益固定・途中低下・途中上昇の6条件で新規対照と比較する。全12実行・1,536実判断、毎手の保存復元・人格固定・実際の学習更新と事後再生を監査する。全個別結果を保持し、全組非悪化・少なくとも1組改善をこの機構診断の確認点とした。現在の登録済み20実行の代用ではなく、一般化や採用の基準も変更しない。計画と途中保存は `results/finite_retry_known_20261031`、実行ソースは `4ca1d16` に固定。

有限の行動方針と終了条件を分ける着想は、[Sutton・Precup・Singhのoptionsの枠組み](https://people.eecs.berkeley.edu/~russell/classes/cs294/f05/papers/sutton%2Bal-1999.pdf)とも対応する。ただし、今回の有限標本・学習する本人・人格の選択は、その理論の改善保証をそのまま満たすわけではない。候補の追加による計算増と誤った予測の選びすぎもあり得る。

競りの途中会計では、完了した2人格の64〜95手に共通の選択損失があった。一方、全長の真の法則による参照選択差は両方プラスで、得点差は一方がマイナスだった。平均予測誤差だけで説明せず、全条件完了後の登録済み診断で調べる。この既知準備課題の修正を、競りの原因や解決と断定しない。

得たいものは、必要な準備を始め、その利益を回収した後は次の目的に戻れる判断。失いたくないものは、人格、実際の経験、意味のある待機、元の全検証条件。結果が揃うまでは試作のままにする。
