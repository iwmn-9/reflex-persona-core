# 関係評価の省略：三段階でも人物の判断は成立するか

## 判断と採否

好悪の細かな強度を行動採点へ直接流す従来方式に対し、「好意的・中立・警戒」の三段階へ省略する `CoarseSocialPopulation` を実装した。相手の搾取を経験して援助を控え、協力が戻れば援助を再開する流れを維持した。新しい人格軸や感情の種類は追加していない。限定した実行経路として採用し、通常の `SocialPopulation`、他ジャンル、先読みの既定を一括置換しない。

省略するのは**行動へ影響させる好悪の強度**。記憶まで消すと、関係修復・忘却・相手の区別を壊すため、観測と有限記憶は従来のまま残した。一般的な人格AIの完成、心理学的妥当性、楽しさの実証ではない。

## 何を得て、何を削ったか

- 得た：好悪による判断を三つの態度として説明できる。小さな好悪の差や弱い単発証拠を採点から省ける。搾取への対応、関係修復、無関係な相手の区別、不運への非帰責、困窮者への配慮は残す。
- 削った：同じ符号の弱い好悪と強い好悪を、行動上の強度で細かく区別する自由。経験の信頼を含む関係信号の絶対値が0.15未満なら中立、それ以上は符号に応じて±0.5とする。
- 増やしていない：人格パラメータ、相手ごとの新しい記憶状態、感情の種類、ゲーム名や人物名による分岐、依存ライブラリ。三段階は既存記憶から都度作り、別の心理状態として保存しない。
- 残した：ゲーム側の実効果・目的・合法手、固定の性格と主義、既存の目的許容幅。嫌悪だけで本人の目的を大きく壊す行動を許す変更ではない。通常反射の数値バッチ経路を使う。

## 固定比較

従来の自作「資源配分」「共同警戒」の2ルール、常時協力・常時搾取・協力→搾取→修復・善意の失敗30%の4相手予定、4人格、16乱数seed、予測のみ・連続関係評価・三段階評価の3方式、各36手。計384実行・1,536 NPCエピソード。4 NPCはそれぞれ独立した台本相手に対応し、四人自由対戦ではない。seed0〜7は前の開発でも使用、8〜15は新しい乱数列で、未知ゲームではない。

比較前に閾値・強度・条件・採否ゲート・実装ハッシュを `preregister.json` に保存した。結果後の係数調整は行っていない。ゲートは群平均の目的利得悪化を0.4以内、死亡悪化なし、協力志向の搾取への対応と修復、人格変更と腹いせなしを要求する。この許容幅は本検証の工学的判断であり、汎用の安全性保証ではない。

## 確認した結果

三段階と連続方式の512対応エピソードでは、目的利得133改善・317同じ・62悪化。本人・seedを対応させた新しい死亡は0。全32条件群で平均利得の悪化は事前の0.4以内だったが、個別の最大悪化は1.92であり、全個体が良くなったとは言えない。

協力志向の例（各条件16seedの合計、利得は1エピソード平均）：

| 条件 | 連続評価 | 三段階評価 |
| --- | ---: | ---: |
| 資源配分・常時搾取への援助 | 163回 | 148回 |
| 同条件の目的利得 | 5.2131 | 5.7475 |
| 共同警戒・常時搾取への援助 | 94回 | 64回 |
| 同条件の目的利得 | 1.7800 | 4.3600 |
| 同条件の生存 | 16/16 | 16/16 |
| 資源配分・協力→搾取→修復の援助 | 128→89→113回 | 128→70→117回 |
| 共同警戒・協力→搾取→修復の援助 | 128→64→124回 | 128→48→119回 |

採点に渡る関係信号の値は、固定したログ内で連続方式5,146種類、三段階方式3種類だった。これは記憶容量や計算費用の削減を意味しない。全行動の切替は11,928→12,036回へ増えているので、「判断全体のぶれが減った」とは報告しない。体力回復や欲求による再選択もこの数に含む。

最も悪化した例は共同警戒・変化相手・seed1の挑戦志向。搾取期の援助が0→2回に増え、利得が1.92低下した。強い好意と弱い好意を同一強度へまとめることで、相手の変化途中の選択にも損失が出る。この境界は省略の代償として残す。

## 開発側の人格・面白さの評価

資源配分の三段階版・seed8・協力志向では、最初は援助を続け、相手が搾取へ転じた後に警戒が形成されて独立行動へ移り、協力の実観測が戻ると援助を再開した。私の評価は「親切さを捨てずに、付き合い方を変える人物」の輪郭が残っている、という範囲。親切だが利用されっぱなしではないことは、対戦や世界の住人としての葛藤を作る材料になる。

ただし、この相手の変化は台本であり、NPC同士の利害から自然に相手が改心した例ではない。プレイヤーが読む楽しさ、複数人物の交渉、意図的な誇張、長期の妥協は未検証。好悪の細密さを省いても判断が成立する証拠と、ゲーム体験が面白くなった証拠を混同しない。
