# 自分たちから協力する／断る判断の接続

各本人が単独案と共同案を自分の人格で比べ、自発的な提案、拒否、別の相手・役割への再提案、全員の同意、実行までつなげた。通常のPolicy、人格係数、世界の物理規則は変更していない。共通処理にゲーム名や「協力なら加点」という分岐はない。

共同警戒では、通信だけ・先読みだけでは維持できなかった生活を、両方の接続で維持できる例が増えた。単独が有利な環境でも全員が協力するわけではない。別構造の共有材料ゲームでも役割を合意できた。一方、物質的な利得の低下、先読みの長さへの依存、未来の再同意を楽観する見積りは残る。全ゲームの既定への昇格や、完成した汎用知能・Rust実用品の認定はしない。

## 実装と交換条件

`reflex/cooperation.py` の `evaluate` は本人だけの人格・欲求・状態・任意の関係評価で共同案を採点する。本人の独立案を上回る案だけを、順位付きの意思として通信する。`negotiate` は未参加の本人から提案し、全員の現在の同意がある案だけを実行する。相手の私的な人格や点数を見て全体最適化する処理ではない。順位は巡回する。拒否されたら別案を試し、合意できなければ独立案へ戻る。

最初の接続で、準備の休息に合意したのに、翌手には別の相手へ移って準備が取り残される失敗を発見した。`continuing` により、未完了の短い共同手順を新規提案より前に再確認する経路を追加した。全員が現在も独立案より良いと評価する場合だけ継続し、拒否や機会の消失では撤回する。検証では準備１手の後に役割を１回実行すると解放する。不運で失敗しても自動延長しない。

- **得たもの**：役割・相手を自分たちで選ぶ合意、拒否を受けた再提案、準備を実作業までつなぐ短手順の継続。
- **払うもの**：未完了手順が双方に有益な間、新しい共同案へ即座に乗り換える機会を一時的に待つ。実際に少量の資源獲得低下もあった。
- **維持したもの**：人格・主義、単独案を選ぶ自由、現在の同意、合法性、経験と想像の区別。協力型の人格への書換えや資源の上乗せは行わない。

境界・条件付き手順・再現方法は [VOLUNTARY_COOPERATION](../../docs/VOLUNTARY_COOPERATION.md)。ゲームは合法な役割と結果のモデルを渡す。今回は既知の役割の全組合せから選び、未知の行動や任意の長い手順を発明するものではない。

## 条件を分けた確認

長期世界は4人／8人、320ターン。交換・共同警戒、自由接触・公開の接触枠、通常・単独有利・共同作業の高負担・160手目の公開変化・体力と活動力の非対称を使う。目的は指定区間末の生存と資源獲得。生理・安全は実状態の差、価値・様式は期間平均で評価する。以前の長期検証の資源獲得だけの目的とは異なるため、当時の成績への単純な上積みとは数えない。

| 構成 | 情報と機能 |
|---|---|
| independent | 同じ人格・社会記憶、１手の正確な公開確率、独立判断 |
| communicate | 上記に、各人の提案・同意を追加 |
| foresight | 独立判断に32手の条件付き見積りを追加 |
| combined | 32手の見積りと提案・同意の両方 |
| continued | combinedに未完了短手順の継続を追加 |

長い見積りは実世界とは別の乱数系列による8標本。条件付きの役割反復・回復を予測し、実行するのは現在の１手だけ。将来の再同意を正確に予測したモデルではない。通信が新しい選択肢と情報を作ること自体が変更点であり、通信なしの比較を万能な既存AIの代表とはしない。

### 短手順の継続：問題例と新しい確認群

最初の共同警戒で死亡した安定志向の人物（92102）は、準備の休息に同意を得ても、その後の仲間の切替で作業できないことが続いていた。未完了手順をつないだ再検査では、この世界の生存が3/4から4/4へ改善した。これは原因を見て改修した開発例で、独立な確認には数えない。

別の乱数列92400〜92401の40世界では、継続追加の20組で死亡回避0・新規死亡0。物質的獲得は20改善・36同じ・24悪化、80人合計で13.15減った。通常・非対称・条件変化を含む共同警戒では、高負担の不可能条件を除き全員生存した。8人・公開接触枠の別の8世界でも全員生存を維持し、追加による獲得差は32人合計で1.87減少した。

短手順を完了する機能として保持するが、無条件な利益向上の標準機能とは認定しない。予測内では何度も同じ相手と働く一方、実際の合意は短い手順の完了後に再交渉する。この先の長期一致は残る課題。

## 違う構造のゲームへの接続

既存の建設ゲームは、共通材料・各人の活動力／技能・同時予約・完成目標を持つ。2人または3人のチーム、通常・疲労・途中の材料減少を比較した。相手チームの未公開の現在手は使わず、既存の公開能力方策で予測する。同じ `evaluate` / `negotiate` を用い、専用の協力ボーナスは加えない。

確認144試合＝72組（乱数列92200〜92211）では、共有材料の予約衝突が3,235→175、両チームの達成点合計が948→2,592。最終達成点は62組改善・7同じ・3悪化。悪化3組は2人チームの途中の材料減少条件だった。自律NPC同士の生産効率の比較で、固定した最強敵への勝率優位を証明したものではない。ここでは既存チーム全員を招いており、自由な仲間探しは長期世界の方で検証した。

## 残る問題と採否

1. **将来の再同意**：現在の全員の同意は検査できるが、それが長期に続く確率はまだ学習していない。短手順の準備放棄を直したことと、長い組織計画の安定は分ける。
2. **先読みの長さ**：別の1乱数列の感度検査では、共同警戒のcombinedは8手・16手で3/4生存、64手で4/4。長さを変えても賢さが安定するとは言えない。32手へ事後的に係数を合わせず、感度結果を残した。
3. **候補と制作負担**：役割の組合せ、結果モデル、回復・完了条件はゲーム側が定義する。未知の手段発明、長期外交、虚偽の約束、通信費用、既存の全戦闘・オークション環境への接続は今回の実証範囲外。
4. **人間らしさの評価**：人格の固定、同じ状況での選択差、実際の協力・拒否は確認した。人間との比較実験や心理学的校正、楽しさ全般の完成ではない。

採用するのは任意の提案・同意・拒否と短手順の実行経路。条件付きの長期見積りを全ゲームの標準にしない。Rustへの移植は、小さくても完成・安定した単位になってからとする。
