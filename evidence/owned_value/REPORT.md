# 学ぶ本人と将来評価を一続きにする

2026-10-17。予測・結果記憶・欲求圧力・進展監視を持つ通常の本人を、将来評価の各経路でも動かす接続を実装した。人格係数やゲーム別の行動補正は変更していない。目的の利益と、そのために通る本人の嗜好・費用を一緒に評価し、実観測後に学んだ本人から読み直す。

採用するのはこの接続契約と、実行した範囲の長期改善。全般的な賢さ、全ゲームへの優位性、人間らしさの完成は認定しない。仕様と研究上の参照は [OWNED_VALUE](../../docs/OWNED_VALUE.md)、現状の優先順位は [PROJECT_DIRECTION](../../docs/PROJECT_DIRECTION.md) が正本。

## 得たものと省いたもの

- **実際に学ぶ本人の継続**：未来の観測でも通常の `DecisionLoop` と `resolve_feedback` を使う。経験・欲求・進展・相手予測の更新を省いた別人の評価を、この経路では使わない。固定の性格・価値観・Policyは保持する。
- **世界と本人の分離**：実観測済みの予測器を固定して世界の応答を生成し、想像内の本人は別に学ぶ。本人が見込みを変えたことだけで世界の確率まで変える初期案は捨てた。次の実観測の後には、新しい予測器を作る。
- **完全な嗜好経路**：将来の目的点だけを追加する近似を外し、欲求・価値・様式・費用の相関した経路も運ぶ。目的点は終点で一度だけ扱い、現在点からの変化として本人へ渡す。最も強い主義の候補層を先に保つ。
- **有界な省略**：主比較は先頭の全応答と、その後15手の学ぶ反射継続。未来の全手で外側の探索を再帰的に呼ぶ費用は負わない。将来の予定された再計画を有限回だけ呼ぶ経路も用意し、別の予測診断で評価した。

この交換で計算は増える。短い流れの読みと比べて、読みの長さ、目的点の扱い、運ぶ嗜好経路が同時に変わるため、成績差を一つの変更だけの効果と呼ばない。通常の数値Policyは維持し、新しい経路は既知の条件付きルールと公開応答予測を提供できる接続で使う。

## 実験の形

一つの世界を**128ターン**続ける。短い試合をリセットして経験だけを持ち越す旧検証とは異なり、資金・負傷・弾薬・設備・満期・本人の経験がそのまま残る。4系統とも同じ共通コア、同じ読みの設定を使う。

| 系統 | 継続する条件と目的 |
|---|---|
| 競り | 公開の賞品列、落札費用、毎手の資金回復、上限資金。本人と相手の得点差と残資金を評価 |
| 資源管理 | 交易、生産先の選択、費用を払って6手後に完成する設備。最終の資金増加を評価 |
| 戦闘 | 弾薬、装填費用、体力回復、周期的な消耗。戦果と残体力を評価、死亡で終了 |
| 賭け | 相手傾向に応じた賭け、見送り、6手後に満期になる資産。最終の資金増加を評価 |

相手の隠れた応答分布は実世界runnerだけに置く。ルール上の応答は0/1/2だが、初期仮説は0優勢・1優勢の二つ。仮説外の2優勢が続く条件と、0→2→1→0へ32手ごとに変化・復帰する条件を使う。NPCにはその予定も真確率も渡さない。公開された応答から既存の学習器が予測を更新する。

比較は、同じ人格・初期状態・公開応答列の三方式。

以下の時点は初回を0とするtick。予測用の標本seed701/702/703は全主実験で共通にし、実世界のseedとは分けた。

1. `reflex`：学習済み予測を使う通常判断。
2. `flow`：通常判断に、8手ごとの3手・3標本の流れの評価を追加。
3. `endpoint`：8手ごとに先頭1手の応答を列挙し、その後15手を3標本で継続。完全な嗜好経路と目的点を評価。

全方式が同じ公開応答を学ぶため、主比較の利益を「新方式だけが良い情報を得た」とは解釈しない。目的の許容幅は本人の候補内の機会差の15%。これは実ゲームでの損失保証ではない。

開発はseed43・2人格・4系統・2条件の16対、48実行。留保はseed170/203・4人格・4系統・2条件の64対、192実行。留保用seedは開始前に記録し、人格係数・読みの設定を結果に合わせて変えない。170は競りの賞品順も変更、203は開発と同じ順。他3系統の物理ルールは同じ。同じseedの人格・条件は乱数列を共有するので、64の独立標本や統計的有意性とは数えない。条件表の凍結はあるが、統計的な採否閾値の事前登録ではない。

## 人物として観測した変化

開発の資源管理・慎重型・変化復帰条件では、通常判断は128手すべて交易、短い読みは123手交易だった。新接続では8/16/24/32手目に設備投資し、生産先を観測に応じて変えた。目的点は0.166667 → 0.477865。最初の32手は準備を含み、その後の生産は0中心 → 2中心 → 1中心 → 0中心へ動く。性格を積極的な係数へ変更した結果ではない。

切替は即座でも完全でもない。最初の未知の変化では40手目に2を選んだ後、0との往復が残った。経験が増えた次の区間では1を32手中30回選ぶ。安定した個性と、変化への追従遅れを別々に観測する。

同じ初期局面の競り（seed170）でも、挑戦志向は入札2、安定志向は1、協力志向は3、自己主張は2を選ぶ。入力の人格差が行動に残る一例。挑戦志向など、設備投資を選ばない人物も残る。固定軸が変わらず行動差が残ることだけで、人間らしさや「本人が意図した損」の科学的な実証とはしない。今回の世界には、信条に関わる社会的葛藤や関係修復はほぼ含まれない。

仮説外の分布を学ぶ部分を外した `endpoint_library` とも、seed170・慎重型・4系統×2条件の8対で比較した。用意した二つの仮説の重み更新は両方式に残すため、「一切学習しない本人」との比較ではない。`endpoint` は7改善・0同等・1悪化。仮説外の傾向が続く資源管理は−0.029948 → 0.308594、賭けは−0.020833 → 0.447917。学んだ見込みが実際の資源と判断へ届いている。一方、同じ条件の競りは0.172119 → 0.160400へ悪化した。予測を学ぶ利益が全環境で保証されるとは扱わない。

## 残った損を切り分ける

**未来の再計画も予測する診断。** 開発で実行済みの4系統×2時点、計8場面から次の15手を予測した。通常の学ぶ反射継続と、次の予定された再計画を一度実行する継続を比較する。平均絶対誤差は0.019704 → 0.016985。ただし2改善・3同等・3悪化で、競りの2場面はともに悪化した。主比較へ常時採用する根拠にはしない。これは実行済み場面の予測診断であり、新しい対戦で成績が上がったという結果ではない。

**候補差が小さい場面。** 留保の悪化を見てから、競り2局面と資源管理1局面を独立の32標本で再評価した。同じ学ぶ反射継続を16手まで追う局所比較であり、その後再計画を続ける128手全体の価値ではない。競りの選択対反射の真確率下の差は、32手目+0.000084（標準誤差0.000822）、64手目−0.000008（0.000581）。少数標本での候補順位と、その後に実現した一つの結果だけから判断ミスや人格の損を断定できない。

資源管理40手目では、選択した生産2と反射の交易の差が、学習モデルで−0.000407、真確率で+0.000203へ反転した。また、この32標本上の目的点だけなら設備投資が両方で最大だが、現行の本人の嗜好層には残らない。目的だけの最善と、本人の好みを含む最善を同一視しない。この事後診断から人格係数を変更することもしない。

本改修は「未来を評価する本人と、実際に経験する本人の接続」を進めた。一方、途中で打ち切った先の評価、わずかな候補差の信頼性、相手モデルの誤りは残る。目的予測の誤差は記録するが、その遅延誤差を直接学習して評価器を校正する機構の完成ではない。

## 捨てた初期案

24手の探索用pilotを主実験と別に残した。目的点だけを延長した初期案、想像内の本人の学習で世界法則まで動かす案は採らない。世界法則を実観測時点で固定し、完全な嗜好経路を運ぶ最終のpilotでも、競りは24手相当の長い読みが0.122396、短い継続は0.210938だった。ほかの3系統で長い読みが良かったことを理由に、この悪化を隠さない。主比較は全系統共通の16手に固定し、ゲーム別の読み長さへ調整しない。pilotの数値を独立した確認群へ加算しない。

## 監査と再現

開発・留保・仮説集合内だけで学ぶ対照の合計248実行、31,744回の実判断・更新。全31,744回の世界乱数と物理遷移を再計算し、31,744回の通常更新対ActorModel更新、固定軸31,744回、保存復元1,488回を照合した。保存した本人から選択と観測を再実行する検査は2,176回、方式間の公開観測・予測一致は20,480回。全体テストは1,105件中1,088件成功、任意の麻雀環境17件はスキップ。最後の境界修正後には接続テスト8件を再実行して成功した。さらに最終ソースで留保の競り128ターンを再実行し、行動・予測値・保存状態を含む全結果が凍結版と一致した。これは全192留保実行を最終ソースで再計算したという意味ではない。各実行ソースは保存してある。最終ソースとローカル検査ログは `final_source.zip`、ハッシュと検査範囲は [verification.json](verification.json) を参照。

ソースの凍結版は [source_snapshots.zip](source_snapshots.zip)。各実験名のディレクトリが実行ソースで、対応する `source_snapshot.json` のSHA-256と照合できる。主実行の全軌跡は圧縮して収録し、物理遷移・実世界の乱数・目的点を再計算する。保存した本人から同じ手と観測を与えた更新も確認する。

PythonとNumPyによるローカルCPU検証。新しい依存、Colab、GPU、LLM推論は使っていない。この実験構成を成熟したRust単位として固定する段階ではない。

```sh
python tools/run_owned_value.py --root results/fresh_development --turns 128 --tail-steps 15 --interval 8 --profiles 0 1 --regimes outside shift-return --seeds 43 --arms reflex flow endpoint --workers 4
python tools/run_owned_value.py --root results/fresh_holdout --turns 128 --tail-steps 15 --interval 8 --profiles 0 1 2 3 --regimes outside shift-return --seeds 170 203 --arms reflex flow endpoint --workers 4
python tools/audit_owned_value.py results/fresh_holdout
python -m unittest discover -s tests -v
```

4系統はこの接続を調べる自作の公開ルール。商用ゲーム、複数勝利条件の長い4X、行動で相手の応答分布が変わる交渉、全員が同時に適応する社会世界への証明ではない。ゲーム側は合法手・ルール・観測・目的の意味を提供する必要がある。共通コアへゲーム名や勝ち手を埋め込まないことと、未知ゲームを自動理解できることを分ける。
