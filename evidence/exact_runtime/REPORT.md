# 同じ長期判断を短時間で検証する実行系

状態: 実行系の同等性確認完了。安定版・Rust・実行中の開発20実行は変更していない。NPCの判断品質の採用判定とは分ける。

長手番を評価することと、検証を長時間かけて実行することを切り離す。現行のH32・3標本・全人格・全世界条件を維持し、参照されない計算と重複した低水準処理だけを取り除く。実行中の研究ソースは `243c42aef2c9da21ccf4e21e4093aa73f8c0f4d7` のまま固定する。

## 除去した費用

- 学習のCDF比較を、加算順序を変えず独立した閾値・次元方向に配列化した。特殊な数値型は従来処理へ戻す。
- 通常の浮動小数入力の有限検査と、疎な効果の既定ゼロを軽くした。継続評価にも既存の単純コンテナ用コピーを使い、オブジェクトや独自コピー規則は標準処理へ委ねる。
- 将来のH1評価で、評価後に参照されない仮想所有者の作成・学習・再判断を省いた。1手・継続なし・所有者監査の取得なしに限定する。公開の通常探索経路は従来どおり。H32を実際に進める仮想本人の学習、実本人の学習・観測・保存復元は省かない。

この最後の変更は、将来の本人の学習を固定する近似ではない。1手の予測分布を返した後、呼出側は通常の判断を行い、次の仮想状態へ進み、同じ学習履歴を更新する。比較に必要な全選択肢・全遷移・全結果は残す。

## 確認と限界

4分野×4人格の経験済み所有者で、1手の全予測・判断・実観測後の所有者・保存復元を比較した。4分野の複数手継続でも、全経路・仮想最終所有者・予測・選択が一致した。既知のH32根では、両実装の全出力が保存済み参照と完全一致した。

最終構成の対応測定は、同じWindows・Python 3.12.14・NumPy 2.3.5・演算設定で実施した。

初期試作に含めた独自オブジェクト複製には、インスタンス単位の `__deepcopy__` を見逃す互換性不具合があり、再現後に全撤去した。最終構成の `reflex/cloning.py` は元の固定科学ソースとSHA-256まで一致する。表は撤去後の再測定値である。

全体1,351件（19件は既存のスキップ）の回帰結果を保持し、最後の撤去以外の全ソースが同一であることを検査した。撤去後は影響する6モジュール・52件を通過し、同じH32全出力と実履歴640手も再照合した。新しいコピー境界試験を含む最終1,352件のカバレッジを、同一ソース部分と修正部分の検証を合わせて確認している。最終ソースで全件を再実行したという意味ではない。既存の安全な実装へ戻す限定差分まで、無関係な検証を最初から重複させない。

完了済みのWindows実履歴5本・640手を約12秒で再生し、学習・所有者ハッシュ・人格・世界乱数を一致確認した。これは保存された行動を入力した整合性検査であり、H32の行動を再計算した確認や新しい長期成績ではない。古いLinux履歴は現在のWindows実行環境で元のソースでも厳密再生に失敗したため、代用しない。

全体回帰をモジュール別に実行する補助処理で、兄弟テストのimport経路が不足していた。該当する6モジュール・36件は標準の探索実行と同じimport経路で通過した。元の失敗ログ、修復後のログ、同一ソースを残し、テスト内容や判定条件は変えていない。
