# 複数手の継続候補を同じ人格で比較する

通常の反射継続より、準備を挟んで目的を達成する条件が増えた。ただし資源管理の自己主張型で達成を失ったため、**汎用経路への全面採用は見送る**。既定の高速判断を置き換えず、任意の研究候補として保存する。

## 得たものと見送ったもの

- 同じ合法初手に対して複数の継続手順を生成し、既存の人格・主義・欲求・目的評価で選ぶ共通部品を追加した。ゲーム名や行動名別の攻略優先表は持たない。
- 全モデルseedへ同じ行動列を適用し、その期待結果で比較する。分岐ごとに最良の手順だけを選ぶ、未来の結果を知った選択は避ける。予定手がその観測で実行不能の場合は、同じ人格の反射へ戻る。
- 従来の反射継続も各初手の候補として残す。モデル内の意図・欲求優先・主義モードを持ち運び、未来の損失と費用も残す。実際には初手だけを実行し、次の実観測で再計画する。
- 追加の計算量を受け入れた。即時判断の既定経路、人格パラメータ、評価係数、実ゲームのルールは変更していない。深さを増やせば自動的に賢くなるという扱いはしない。
- 勝利の合計が増えたことを理由に、一部人格の悪化を許容する採用は見送った。物流だけを特別扱いして自動的に新方式へ切り替える実装もしていない。

## 固定した比較

全56エピソード、28組の対比較。`preregister.json` に全ソースのハッシュ、全条件、採用基準を実行前に固定した。人格は挑戦・安定・協力・自己主張の4種類。方式は前回の根拠付き停滞解除＋反射継続（verified）と、同じ実行経路に継続候補探索を足したもの（search）。観測監視の未来モデル追加は今回の候補へ混ぜていない。

共通の設定は期間6、beam幅2、初手後の探索長2、目的許容幅0.15、停滞解除の改善幅0。残りの未来は同じ人格の反射で補う。各初手の候補を既存の主義優先層・目的許容幅・人格スコアで絞る。新しい報酬係数の調整や教師学習はない。

診断16エピソードは、前回使用済みの物流2条件（期限8/容量2/供給3、期限10/容量3/供給2）。留保40エピソードは、物流2条件（期限11/容量3/供給3、期限10/容量2/供給2）、複数資源・複数勝利条件（期限14）、オークション（賞品9→14→6、予算11、公開後の相手入札変化）、戦闘（HP7/距離4/期限7）。留保条件を見た後の候補調整はしていない。

留保は既知の4ルール系の新しいパラメータ組合せで、未知ゲームへの転移や代表的な強さを証明するものではない。戦闘の実seedは280の1本、モデルは820..823で分離。オークションは4人だが相手方策の幅は限定的。物流は単独の公開・決定的な工程管理である。

## 結果

| 条件 | 従来 | 継続候補追加 |
|---|---:|---:|
| 物流・使用済み診断条件の達成 | 3/8 | 6/8 |
| 物流・留保条件の達成 | 7/8 | 8/8 |
| 資源管理・留保条件の達成 | 4/4 | 3/4 |
| 戦闘・留保条件の勝利 | 0/4 | 3/4 |
| 戦闘・生存 | 4/4 | 4/4 |
| オークション・正規化実得点合計 | 2.068966 | 2.068966 |

留保20組では、目標結果が4組改善・1組悪化・15組同じ。物流で達成可能な経路を失った件数は診断5→2、留保1→0。これは実行後だけに行う全合法手の到達可能性診断で、探索・選択・教師へは渡していない。人格上の価値を無視した到達可能性なので、この件数だけで本人の非合理を断定しない。

戦闘では挑戦・安定・自己主張が勝利へ変化し、協力は引分けのまま。安定型に移動の往復が1件生じたため、不要な往復を解決済みとも言わない。資源管理の不足発生は合計1→0だが、勝利を失った代償を相殺する合格理由にはしない。

人格差は残った。物流の自己主張型は、期限11/容量3/供給3では契約6を達成し、期限10/容量2/供給2では共同体4へ切り替えて達成した。使用済みの短い2条件では契約納品3/4にとどまり未達のまま。全人格の勝率や選択を同じにする調整は行っていない。

## 悪化した箇所と次の課題

資源管理の自己主張型は、従来の成功から期限引分けへ悪化した。選択時のモデルは成功を見込むが、その後の実際の再計画では必要な訓練を先送りした。

- round=7の予測は `claim → gather:food → train` で成功。
- 次の実観測からは `gather:food → claim → build:farm ...` となり、予定の `train` を実行しない。
- 後の予測にも `train` を含む成功経路が繰り返し現れたが、実行列は締切まで完了せず、終盤には予測も引分けへ落ちた。

計画の実行を固定するだけでは、変化した状況へ対応できなくなる。次はゲーム名に依存せず「前の計画を続ける案」と「変更案」を同じ目的・人格・残り期間で比較し、必要な準備の延期を無償扱いしない仕組みを検証する。今回の軌跡はその失敗を特定する材料であり、その対処を実装・検証済みとはしない。

他にも、有限beamが早期に捨てた長期準備、途中で観測に応じて分岐する戦略、非終局評価の正確さ、相手の適応や学習との統合は残る。ゲーム側の合法性・公開状態・遷移・目標/効果の意味づけは引き続き必要で、ルール文章だけから汎用的な価値を獲得したモデルではない。

## 検証と再実行

ローカル588件実行、任意麻雀依存の14件skip、失敗0。追加6件で、同じseed集合へ共通の手順を適用すること、実行不能時の合法な反射、全初手の被覆、終局後の停止、探索長0の従来互換、複数候補間の主義優先と実初手への意図復元を確認した。

`tools/audit_search_transfer.py` は56エピソードの426実ルール遷移、保持候補と従来継続の29,929モデル遷移、3,488保持候補、実人格状態・圧力・進行監視の更新と最終選択を再生した。保持されなかった探索ノードの最適性を証明する監査ではない。ソース固定と分岐共通手順を照合。軌跡SHA256: `f0c87c47cd62362e13f0d154852fb5e27f4a822d06171d092da3bc08705204e9`。
