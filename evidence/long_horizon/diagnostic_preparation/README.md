its unchanged frozen worker, the predeclared resolver and every factual root
input to the existing execution driver. It does not execute or adopt a policy.

The retained rehearsal reproduced the previously completed 72 evaluations /
12 roots / six adverse conditions exactly, including every input and both
operational program hashes. It did not rerun those forecasts. Incomplete and
corrupted archives, another worker, existing output and path escapes were
rejected. A Windows temporary-path length failure was found and corrected by
using a short sibling staging name; the final original input names are retained.

the current original process, require all 20 executions / 2,560 actual steps,
archive, prepare all registered loss diagnostics, execute them on the original
worker, then archive their results. It does not schedule repetition, silently
restart interrupted science, qualify adoption or launch independent confirmation.
Synthetic process-wait and incomplete/failure gates passed. The actual chain was
still waiting for the original cohort when this record was produced.
