# 予測標本で変わった一手の長期影響

**登録済みの診断。完走結果ではなく、独立40組の代用でもない。** 人格や判断器は変更しない。

前回の4局面・12比較で予測標本により選択が変わった。そこで、別の標本が選んだ異なる手をすべて残した5分岐を、実際の学習・再計画を伴って終局まで動かす。局面の追加・削除や、有利な予測乱数への置換は行わない。

1. 元の実履歴を判断直前まで再生し、世界・人格・本人の記録・乱数を照合する。
2. 元と同じ手を打つ対照で、次の通常H32判断が保存済み実行の選択・予測値・経路・本人・世界と完全一致することを確認する。対照の終局結果は、完走・監査済みの元履歴を使用する。
3. 別標本が実際に選んだ手を、その一手だけ実行する。同じ手を選んだ標本は、同じ実結果・本人を作るため、重複する独立試行として数えず来歴を併記する。
4. 以後は元の凍結H32構成と元の予測乱数701/702/703に戻し、毎手の実結果で本人を更新して、元の128手の終局まで進める。各手で途中保存し、停止時は同じ本人・世界乱数から再開する。
5. 実得点差、条件付き期待増分差、参照評価の会計を比較する。良化も悪化も残し、全履歴を再監査する。

これは「別の標本が選んだ一手」の因果的な影響を、同じ世界乱数の一本の経路で調べる診断である。すべての手で予測標本を替える方式の評価、世界全体の期待値、独立した人口集団の評価ではない。局面を既知の損から選んだ偏りもある。結果を元の40組へ混ぜたり、結果のよい枝で元の成績を置き換えたりしない。

`plan.json` は実行前の登録、`harness_test.json` は比較処理を確かめた別の6手の試験。短い試験は品質評価へ加算しない。試験では元の再開判断の完全一致、一手だけの介入、人格と実学習の再生、同じ世界乱数、途中再開、完了結果の重複実行防止、不正な手と改変された入力の拒否、元データの不変を確認した。実装は `tools/continue_sampled_roots.py`。実行時は登録したバイト列を別保存し、判断器は従来の凍結ソースを読み込む。

実行状況はローカルの `results/selected_root_continuations/status.json` と `runs/*/checkpoint.json`。完走後に全5分岐の監査結果が揃って初めて診断の結論を記載する。元の40組は別の6プロセスで継続する。この有限の比較は定期実行ではない。

短い比較処理の検査は、リポジトリから `python -I evidence/long_horizon/selected_root_continuations/reproduce_harness.py` で再現する。固定ソースを新しい一時ディレクトリへ展開し、元データや実行中の比較には触れない。`harness_test.py` は当時の検査ソース、`harness_test_inputs.zip` はその記録であり、直接実行する入口は `reproduce_harness.py` とする。計算時間を含むファイルのハッシュは再実行ごとに変わるが、実結果・本人と世界乱数の再生・監査結果を照合する。
