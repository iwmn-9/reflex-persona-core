# Unknown response templates, preserved personality

Python research only; no adoption or long-play improvement is claimed. Stable v0.1.0, its source and Rust are retained. The authoritative experiment contract is `plan.json`; `registration.json` and `source.zip` bind the computation. This checkout is separate from the still-running frozen eight-sample study.

The candidate changes the categorical world predictor used by both factual learning and hypothetical futures. The original half-prior on supplied labeled hypotheses stays unchanged. Within the unknown half, an equal mixture compares fresh Dirichlet laws with label permutations of supplied probability shapes. This proposes an unprovided tendency without knowing which response is actually favorable. It does not create actions or learn preferences. It uses no game/action-name branch, evaluator law or future real observation. Exact permutation completion is bounded to at most four response categories; larger alphabets and empty libraries retain the original predictor.

The structural assumption is that an unknown tendency may share a supplied probability shape. It can be wrong. Simple empirical reuse and wholesale label symmetrization were screened and rejected as default replacements. Pure symmetrization's fresh 128-stream result, including its loss of labeled priors, is retained in `../adverse_symmetric/prediction_screen/`. The final hierarchy's separately registered 128 streams / 16,384 observations are in `prediction_screen/`: ten of twelve changed alphabet/pattern groups improve mean expected log regret and Brier excess; the three- and four-category novel-shape groups worsen. All four five-category groups match the unchanged fallback exactly. Those scores are prediction evidence, not game-intelligence acceptance.

Both fresh stable controls and the candidate use the original H32 / seeds 701..703, full factual learning, the same retry continuations and H2 recovery, personality, world RNG and 128-turn rules. The same ten conditions, every individual adverse result, and all original family and improvement gates are retained. Only full development completion, source/history audit and persona review permit the unchanged independent forty-condition comparison against H16 and stable H32. No prediction-only or local-root result can pass that gate.

`preflight_tests.json` records exact small-model enumeration, maintained initial labeled priors, full/resumed decisions and learning across all four rule families, save/restore, hypothetical-history isolation, and complete-only accounting tests. These are execution integrity checks. No new public production API or Rust migration is part of this experiment.

What this candidate may gain is learning an unprovided tendency from a reusable structure instead of starting every unknown law from an unstructured prior. It spends inference work and can lose when that structure is inappropriate. The long-play study, not this explanation, determines whether that trade is useful.
