# 完了した2条件の全手会計

元の開発20実行のうち、両腕が完了した競りの人格2・3を個別監査し、
全512手の実履歴を残した。良否による抽出ではなく、この時点で完了した
両腕だけが対象。コホートの採否、事前登録した診断局面の選定・予測再計算は
行っていない。

人格2の最終差は+0.0009765625、条件付き増分差は−0.0085205078。
人格3は−0.0129394531、−0.0010498047。候補の64〜95手目は両人格とも
31/32手で保存された目的値の最大を選ぶ一方、現在の予測を固定するH32参照では
17/32手が最大ではなかった。参照は人格と将来の学習を省くので、この差を
人格の誤りや探索だけの不具合とは断定しない。

全ての実際の判断窓について、`実終点−保存予測値` を次の3項へ分解した。

1. 実際の増分と、その実行経路上の真の条件付き増分との差。
2. 同じ実行経路上の真の条件付き増分と、その時点の本人の予測との差。
3. 実行経路上の本人の予測を足した値と、起点の保存予測値との差。

3には将来の行動・情報・状態の変化、予測標本、継続近似が混ざる。
全項の和が元の差と1e−12以内で一致することを全512窓で確認した。
重なる窓は独立標本ではなく、経路上の条件付き増分の和は、別の方針の
期待終点を表さない。隠れた真の分布は評価だけに使った。

候補の32〜63手目では、実終点−保存予測値の平均が約−0.01903、上の3が
約−0.01313だった。64〜95手目では両者の符号が反転し、実終点との差は
約+0.04224、3は人格2で+0.02380、人格3で+0.02216となった。
従来側より実経路の予測誤差が小さくても、将来判断との残差は減るとは限らない。
一律の楽観補正や、一律に予測値を下げる修正を正当化しない。

元の全20実行を完走・監査し、全悪化を事前登録の同じ規則で調べる要件は
維持する。この会計は進行中のチェックポイントを読まず、判断器も変更しない。
