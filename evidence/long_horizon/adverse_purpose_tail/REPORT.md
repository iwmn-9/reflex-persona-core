# 将来の通常判断と、既存の一手の目的評価の接続

元の転用予測候補は全10条件を完走・監査しても賭け分野の基準を満たさなかった。慎重型の条件付き資金差−9は、利益になる準備を3回少なく選んだ会計に対応する。予測誤差の平均改善だけでは、判断の改善にならなかった。

その96手目を元のLinux環境・人格・実際の学習履歴で再現した。目的の平均だけを本人の採点へ揃える診断は、この局面を含む9予測で選択を変えなかった。既存の厳密な同点補正も、予測内で観測した33個の本人状態で選択を変えなかった。どちらも今回の解決策として重ねない。数値と元の選択の完全一致は [診断記録](causal_diagnosis.json) と [保存物・診断ソース](causal_diagnosis.zip) に残す。

準備の収益を受け取る将来の手番では、粗い即時効果が上限で揃い、追加で利益を狙う手の差が見えにくくなっていた。本人は様式の差も評価して待つ方を選んでいたため、完全に同じ効果・様式にだけ作用する同点補正では解決しない。実履歴96手と予測内6手を厳密に再生し、同じ将来の本人へ既存の一手の目的評価を渡した別コピーでは、待つ選択から本人の予測に沿う選択へ変わった。人格の重みや本物の未来は渡していない。

候補 `tail_purpose_reflex=True` は、既存の二手回復が起動しない通常の将来判断へ `owned_rollout` の一手評価を接続する。32手の長さ、予測標本、転用学習器、仮想学習、主義・欲求・様式・リスク評価、反復を試す候補は保つ。ゲーム名・行動名による分岐はない。既定値はFalseで、採用済み構成は変わらない。実験実行器の `transfer_purpose` だけが明示して有効化する。

得たいものは、収益の粗い表現に埋もれた選択の差を、既にゲーム側が提供している目的評価から使えるようにすること。捨てる候補は、正の即時効果があるだけで将来の本人の目的評価を省く近似。追加計算が必要になり、一手評価も実際の32手再計画と等しいわけではない。局面の選択変更だけを長期改善とは扱わない。

短い検査で当初「5操作の準備をH8でも選ぶ」と想定したが、従来構成も選ばなかった。反復候補が途中の次周期へ支出する既存の候補不足が理由で、H10では旧・新とも準備を選んだ。H8の同等結果も検査へ残し、この限界を新構成で解決したことにはしない。

別の接続修正候補は、完走した唯一の賭け条件で実得点が上がっても条件付き利益が低下した。この分野の不合格は他分野の結果では相殺できない。残りの実行と全悪化診断は省略せず完了する。この追加候補はその構成へ重ねず、転用予測候補の未来の通常判断にだけ目的評価を接続する。元の開発10条件・新しい同条件の対照・全悪化レビュー・予約済み独立40条件の基準を変更せず、登録を分ける。局面だけ、途中結果だけ、単体検査だけでは採用しない。

同じ96手目で32手予測を完了した [比較](root_comparison.json) では、従来側は元の判断・目的値・選択監査・候補対応・予測歩数を完全再現し、`bet:2` を選んだ。接続側は `bond` を選んだ。人格は同じで、予測した物理歩数も両方2880。既に見た局面での予測修正であり、二つの異なる予測の目的値を実現利益の改善として比較しない。入力・590ファイルの固定ソース・両予測・監査を [保存物](root_comparison.zip) に含める。
