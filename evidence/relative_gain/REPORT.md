# 準備の成果と通常の収入を区別する

状態: 未採用のPython研究候補。既定の終了条件、安定版、Rust、稼働中の目的評価接続・利益回収の世界比較は変更しない。

先行候補は、予測上の公開目的値が開始時より増えれば、反復する準備を終えて同じ本人の通常判断へ戻る。5手準備の課題に、どの行動でも等しく得られる毎手1.125の収入を加えると、初手の準備自体はまだ未完了でも条件を満たした。その結果、24実手の最終資金は、収入なしでは48から48を維持する一方、共通収入ありでは63に留まり、同じ合法手で可能な75を逃した。全行動の合法な結果を列挙する参照で、失った12を実判断の履歴へ分解した。これは公開目的に対する参照であり、人格の価値を現金に置き換える基準ではない。

隔離修正では `retry_gain_reference='ordinary'` を明示した場合だけ、同じ強制初手の応答と同じ予測乱数で進む通常判断経路の、同時点の目的値を上回るまで反復する候補を評価する。両経路の仮想本人は実行時と同じ学習を続ける。現実で複数手を強制実行せず、実観測のたびに再計画する。元の通常判断案と全期間反復案は残す。人格の重み、目的の定義、準備の長さやゲーム名は判定へ追加しない。

全4実行・96手の修正比較では、収入なしの48を維持し、共通収入ありは63から75へ改善した。どちらもこの24手課題の最大資金に一致した。元ソースでの診断4実行も合わせて全192手の世界・実学習・人格・毎手復元を監査し、修正ソースの旧条件の全履歴が元ソースと一致することも確認した。[全履歴・固定608ソース・監査](boundary.json)。独立な条件は2つであり、8実行を8種類の汎化成功とは数えない。

関連14テストを通過した。確率的な4分野で元の通常判断・全期間反復の全予測経路が変わらないこと、応答と乱数が対応した経路を比較すること、人格による利益の譲歩・欲求優先・行動名変更を確認した。既存のH32長い準備と資金不足、過去の終了条件のテストも維持した。全体回帰や新たな世界比較の通過ではない。

続く長期診断は先行10組すべてを残し、共通収入下の採算の良否を2人格ずつ加えた14組。旧終了条件と修正条件の28実行、各128手・計3,584実手を同じソースで比較する。実学習、世界乱数、人格、毎手の復元と完走後の全履歴を照合する。全組非悪化、追加の採算がよい2組で厳密な改善を要求し、悪化は除かない。この診断も登録済み世界比較・全悪化診断・独立40条件を代替しない。

得たものは、予測の揺れや人格のための損とは別の、利益の帰属に関する具体的な原因と共通修正候補。捨てる候補は「開始時より増えた」という条件だけで準備の成果とみなす解釈。長期での採否は未確定であり、新たな人格機構や終了時刻のパラメータは増やしていない。
