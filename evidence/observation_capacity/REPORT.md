# 停滞を崩すための調査と機構診断

**得た手掛かりは、未来の観測に応じて変わる計画を探索候補として表現すること。** 長い同じ行動列を増やすだけでは届かない種類の判断があると、既存の予測・人格採点への接続で確認した。もう一つは、全枝の非悪化という保護条件が、知識の確かさや人格のリスク選好を表す条件ではないこと。既定の制御器・人格係数・依存関係は変更していない。

これは探索方向を選ぶ機構診断であり、汎用知能や実ゲームの勝率を改善した研究ではない。前回の [repair_stability](../repair_stability/REPORT.md) の停滞を、今回解消済みとは扱わない。

## 調査で見つけた接続先

1. [POMCP / Silver・Veness, 2010](https://papers.nips.cc/paper_files/paper/2010/file/edfbe1afcf9246bb0d40eb4d8027d90f-Paper.pdf) は、隠れた状態でなく、行動と観測の履歴を探索ノードにする。世界の仮説は遷移の計算に使い、同じ観測履歴から異なる私有状態を見分けて行動しない。条件付き方策を読むための具体的な表現になる。論文の収束条件には正しい信念分布などが必要で、本コアにその保証を移植できるわけではない。
2. [DESPOT / Yeほか, 2017](https://arxiv.org/abs/1609.03250) は、限られたシナリオで巨大な条件付き方策を探すと起こる過適合へ、方策の表現サイズと標本上の価値の釣合いで対処する。今回アルゴリズムを実装したわけではない。観測で枝分かれできれば何でも良いという楽観を避ける参考にする。
3. [SENTINEL / Erikssonほか, 2022](https://proceedings.mlr.press/v180/eriksson22a.html) は、環境そのものの偶然と、知識不足による不確かさを区別して扱う。採用する着想はこの区別であり、ニューラル学習器や新しいリスク軸を人格へ足すことではない。
4. [多目的逐次判断の整理 / Roijersほか, 2013](https://roijers.info/pub/roijers13a.pdf) は、効用の形や確率的な方策の許容によって、適切な解と算法が異なることを整理している。本コアの動く欲求・人格採点・価値層・目的許容幅を、単一の固定報酬の探索へ黙って置き換えない。単純な期待勝率最大化は比較用に限定する。

流行の新しさより、現在の失敗を説明できることを選定基準にした。外部コード・追加ライブラリは取り込んでいない。

## 現在のコードとの違い

`continuation_search.search_forecast` は、全予測枝へ同じ行動列を適用し、違法になった手だけ本人の反射へ戻す。**反射の継続自体は既に観測に反応する。** 不足しているのは、まだ合法だが今の観測には適さない手を変更するような、探索された条件付きの継続候補である。

`policy_rollout.evaluate_policy` にも、未来の公開局面で基準制御器を呼ぶ既存機構がある。これを再発明する要求ではない。ただし基準方策の評価と、観測履歴による探索方策の生成は違う。実行時に外側の追加器を毎回使う場合、その新制御器まで同一に予測しているわけでもない。

`replan_check` は次の局面で一度だけ再判断し、以降は共通の手順に戻る。複数回の変化に応じて計画を修正する能力を、現在の選択へ織り込むには不足が残る。

## 小さな完全既知モデルでの確認

公開ルールに基づく遅延投資を用意した。現在は確実な得点か投資を選ぶ。投資すると後で二種類の機会のどちらかが現れ、その機会に合う準備は終局で1、合わない準備は0となる。途中の小さな取り分は0.2。準備は即時には小さな負担なので、通常の反射だけでは取り分を選ぶ。どの準備も両世界で合法であり、違法手への反射代替では救済されない。

情報が後で見える版と、終局まで見えない版を必ず両方扱う。モデルは二つの世界が等確率であると明示し、未来の実乱数は選択器へ渡さない。行動名は意味を持たないIDで、入れ替えた対照も行う。これは能力限界を識別するための自作環境であり、そのまま実ゲームの分布を代表するものではない。

コードを `f0d4d08` で凍結してから、3/5/8手の五つの期間・情報開示時期、見える/見えない二条件、確実な得点0.6/0.75/0.9、既存四人格を全て組み合わせた。**120条件は30種類の同じ検証環境×4人格で、独立120試合ではない。** 設計・事前の二つの接続確認は探索的に行っており、未知ゲームに対する留保確認とも呼ばない。

| 投資案の表現 | 後で情報が見える | 情報が見えない |
| --- | ---: | ---: |
| 全て調べた共通の固定手順 | 0.5 | 0.5 |
| 同じ観測履歴には同じ手を取る方策 | 1.0 | 0.5 |
| 禁止される世界の真値を見た方策 | 1.0 | 1.0 |

この表は期待終局得点で、勝率ではない。条件付きの方策は目的だけを使う小さい全探索診断器で生成し、独立した前向きの全列挙でも照合した。現在の `flow_rollout` の継続コールバックへ、公開観測履歴だけをキーとする凍結方策を接続する。人格採点・目的のゲートは既存の `goal_forecast` と `select`、有限主義の同じ `Policy` を使った。

- 情報が見える60条件では、既存の共通手順探索は確実な0.6/0.75/0.9を取り、条件付き候補の追加は投資の1.0を取った。
- 情報が見えない60条件では、両方とも確実な得点を選んだ。隠し世界を見れば作れる架空の1.0を使わなかった。
- 行動IDを反転した8条件でも目的値は一致した。
- 各選択を二つの可能な世界で終局まで実行し、モデルの期待値と照合した。8個の予測seedは同じ二世界を繰り返すので、新しい独立標本として数えない。

これはサンプル数や読みの長さでなく、表現できる候補の差である。固定手順の値は近似ビームの成績だけでなく、全手順を調べた上限も0.5だった。ただしこの環境には人格間の利害衝突を与えていない。同じ手を選んだことを、人格保持・人格の面白さの実証としない。目的だけで生成した方策をそのまま汎用NPCへ採用することもしない。

## 非悪化ガードを別の角度から診断

既存の `repair_stability.safeguard` に、完全に既知の二分布を渡した。基準の得点は0.4/0.6、候補は0.5/0.7で、期待値は0.5から0.6へ上がる。人格と目的は同じにする。

- 対応を `(0.4→0.5, 0.6→0.7)` と置くと採用。
- 対応を `(0.4→0.7, 0.6→0.5)` と置くと拒否。

同じ二つの周辺分布でも、宣言した枝の対応で結果が変わることを、実関数で確認した。これはコードのバグとは言わない。元の規則が要求する**対応枝ごとの優越**は、分布の優越や知識の信頼度より強い、別の性質だという診断である。世界の対応自体に意味がある場合もあり、対応を都合よく並べ替えて採用する修正はしない。

前回、合理的なリスクを含む二つの改善がガードで消えた事実と整合する。これを人格の慎重さに押し付けたり、全員の乱択率を上げて回避したりしない。外側ではモデルの適合・標本の不足を扱い、内側では本人の既存の目的・欲求・主義から結果分布への態度を決める必要がある。具体的な信頼境界の校正や新ガードは、今回未実装である。

## 得たもの・見送ったもの・次の受入条件

得たのは、探索量だけでは解決しない表現不足の再現と、既存部品へ条件付き候補を接続できる証拠。心理パラメータやゲーム別の補正係数を増やす必要はなかった。見送るのは、長い固定列と保護条件を足し続ける方向、および論文の最適性保証を本コアへ借りる説明である。

次の実装対象は、公開観測履歴と複製した本人状態から選ぶ有限の継続方策。ゲームは観測の投影・遷移・目的尺度を供給し、コアは秘密の状態・seedを方策のキーにしない。候補の生成と比較には既存の人格採点を接続する。未探索の履歴は宣言した本人の基準方策へ戻し、観測後は実際に対応する枝だけを引き継いで必要な箇所を修正する。最適な得点だけで全人格を同じにする方策は受け入れない。

採用には、競り・複数資源/勝利条件・戦闘の実際の終局結果で、現在の反射・共通手順・条件付き候補を比較する。遅延投資や不可逆な決定を含む環境を使い、強い基準が既にほぼ全手で上限を取る検証の天井も確認する。人格別の悪化、予測と実際の継続の違い、情報を見られない条件での架空の利得を別々に報告する。今回その受入検証まで完了したとはしない。
