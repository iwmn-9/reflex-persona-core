# 関係経験を人格判断へつなぐ比較

## 目的と今回の判断

人間が細かい軌跡から人格らしさを鑑定することを成果にしない。開発側が、人間の行動について知られたパターンに照らして「表現できたこと／単調なこと／人格を理由に判断を壊したこと」を評価する。今回補ったのは、相手の予測を更新しても、援助という行為の価値が一定で接し方が変わりにくい弱点。

既存の人格Policy、観測した相手別の関係評価、目的の許容幅を組み合わせた。感情を人物別の台詞やゲーム名のif分岐で演出しない。`reflex/social.py` はゲーム名・行動名・勝利ルール・プロフィール名を参照しない。ゲームは、行動の相手と援助/害の向き、相手の切迫度、観測した本人への利益/害と帰責の有無を供給する。

認知的評価と感情的意思決定を別部品として接続する先行例として、[FAtiMA Toolkitの公式構成](https://github.com/GAIPS/FAtiMA-Toolkit)も確認した。今回の実装はそのコードやOCC全体系を取り込んだものではなく、相手別の評価に絞った小さい独自部品。新しい外部依存・LLM・訓練・心理学的な実証を追加していない。

## 接続した仕組み

- `SocialMemory`：一相手につき、有界な関係評価と証拠量・観測時刻を保持。最大64相手、時刻による減衰、上限での古い相手の忘却、重複観測拒否。協力が戻ると関係を修復できる。
- `SocialBinding`：現在の合法候補の相手と、援助/害の向き・切迫度。人物に固定した新しい性格軸ではない。援助の相手を誤って結び付けた入力は拒否する。
- `Policy.decide(..., appraisal=...)`：事実の効果・確率・欲求・価値観を変更せず、別の主観評価を加える。有限優先の人格採点と合法/既知失敗マスクをそのまま使う。
- 目的許容幅：好悪で選ぶ案は、現在の目的見込みの最良から既定.15以内か、もともとの人格判断以上の目的値が必要。元から本人が選ぶ大きな信条の犠牲は残すが、腹いせでそれ以上に目的を壊す案は除く。基準はゲームの予測値であり、現実の安全保証ではない。
- `SocialPopulation`：数値バッチ反射→同時解決→実観測の接続。フィードバックの一部が不正なら全員の関係更新を拒否。未来の観測を拒否し、バッチ順序で人物の選択を変えない。無指定の従来Populationは変更前の選択を維持する。

相手に対する好悪を、その相手が次に協力する確率へ流用しない。今回の基準と追加版はともに同じ観測済みの直近8応答から予測する。新部品によって相手の内心や未来を知ることはない。特性から関係更新速度を決める係数は工学的な仮定で、Big Fiveとの心理学的因果を実証したものではない。

## 固定比較と結果

四つの固定人格×8seed×2ルール×4相手条件×2設定＝512 NPCエピソード、実判断18,348件。各NPCは36手、相手は独立した固定スクリプト。資源配分と共同警戒という小さい自作ルールで、自由対戦や人間被験者の試験ではない。相手は常時協力、常時搾取、12手協力→12手搾取→12手修復、協力するが失敗率30%の4条件。搾取の原因が観測できた時だけ害を帰責し、明示された不運は帰責しない。

肯定的な関係証拠は、公開された相手の支援行動を+.8とするゲームの意味付け。自分が独立行動を選んだ時にもその支援は観測するが、必ず自分の物資やHPが増えるという意味ではない。否定的証拠は、自分の援助を相手が意図的に利用した時の-1。これは確率予測用の実利得サンプルと別の入力であり、実利得として学習しない。

死亡後のNPCは終了状態となり、行動・利得・学習を続けない。原本は `social_appraisal_final`。最初の生成はNumPy boolのJSON化で中断、次の診断で死亡後の処理不備を発見したため修正し、固定係数を変えずにfreshな出力で全比較を再実行した。失敗版は最終比較に混ぜない。

| 協力志向、8seed合計/平均 | 予測だけ | 関係評価も接続 |
| --- | ---: | ---: |
| 資源配分、常時搾取への援助回数 | 171 | 83 |
| 同条件の平均目的利得 | -0.794 | 5.106 |
| 共同警戒、常時搾取後の生存 | 0/8 | 8/8 |
| 同条件の平均目的利得 | -3.200 | 1.600 |
| 資源配分、変化相手への援助（協力/搾取/修復期） | 64/63/55 | 64/44/57 |
| 共同警戒、変化相手への援助（同上） | 64/49/57 | 64/32/64 |
| 資源配分、善意の失敗30%時の平均目的利得 | 8.068 | 7.730 |

他の三人格が搾取的相手へ援助しない傾向と、目的利得は維持した。良い関係では自己主張型も限定した援助を選ぶようになり、資源配分の常時協力条件で利得11.390→11.064へ低下。成長志向は共同警戒の途中変化条件で10.708→10.243へ低下した。好意が現在の予測を上回る小さい損を許すため、全条件の強化ではない。

全比較で特性/主義の変更0、腹いせ行動0。失敗したゲームで常時変わらない正解を強制した結果ではない。単体検査では、有利な自己行動があっても援助する選択を残すこと、悪い相手の記憶が無関係な相手へ転用されないこと、関係修復・時間減衰、不運の非帰責、違法/既知失敗の維持、悪い腹いせの拒否、チェックポイントの人物所有、重複拒否、バッチ順序と原子的更新を確認した。

## 私の評価、得たもの、捨てたもの

今回「人間の性」に近づけた部分は、協力的であることと、利用される相手に接し方を変えることの両立。悪い相手に失望しても全員を嫌いにならず、関係が修復されれば協力へ戻れる。本人が協力的なままという軸があり、状況と経験で行動が変わる。判断コアに実行結果を返す経路があるため、性格の看板だけの違いより一段進んだと評価する。

得たものは、相手を覚えた選択・限定した恩返し・失望と修復。捨てたのは、援助という行為へ毎回一定の好ましさを与える扱いと、好悪がどれだけ目的を損なっても許す自由。固定人格・意味ある自己利得の犠牲・合理的な回復や待機は削っていない。証拠が薄い時は大きく変わらず、搾取された相手への援助が完全に0になるようには調整していない。

まだ人間全体の模倣ではない。誇りの傷付き、自己正当化、長い目的の妥協、他者の誤解や噂、関係の駆け引きまでは今回の一変数の評価では表現しきれない。援助が途絶えた時の害の意味も、ゲーム側が定める。目的見込みが間違えば許容幅も誤る。今回の関係評価は反射のPolicy/Populationへ接続した経路で、DecisionLoopの将来探索・相手仮説・checkpoint全体への伝播は未接続。全NPC・全ゲームへ既定で有効化しない。

この不足を「数値を人間が眺めて採点すれば完了」とは扱わない。今回の挙動と回帰を踏まえ、次の組み合わせが必要な範囲を開発側が判断する。
