# 有限の見返りを毎手の再判断で回収する試験

結論: 共通の人格付きflow継続と実行中の再判断を接続し、回収/予測と実行のずれを検査できた。ただし新しい自己継続方式は標準へ採用しない。予測した次の手との一致が増えても、目的達成の品質は保証されなかった。

## 条件と比較

12配置×4既存人格×3方式。戦闘4配置だけ実seed190/191で反復し、合計192エピソード=64組の3方式比較。独立192種類のゲームでも、未使用大標本の強度評価でもない。全方式が実行時には毎手再判断する。初手後に固定手順を強制する比較ではない。

- reflex: 即時の既存Policy。
- scripted: 前回と同種の待機/次のbid-4/射撃・装填を未来予測に使い、実行は毎手時間評価で選び直す対照。
- persona: モデル上の次状態から欲求を再構築し、同じ人格Policyの即時判断を未来の継続に使う。実行は毎手時間評価で選び直す。

予測期間は全条件6step。実際の期限は資源2/6/12roundと飢饉8round、競り2/3round、戦闘1/8tick。公知の期限/本人死亡以後はゼロ増分。終局以外の未知の未来をゼロ埋めしない。モデル戦闘seed800/801と実190/191を分離。4人競りの景品予定は公開で、隠し山札の順番を参照する試験ではない。

資源は既存4人ルールで他3人がwaitする生産/支出ストレス試験。勝利レースの一般評価ではない。競りの相手は公知bid-3から、別条件で未予告bid-5へ変更。モデルに変更時刻/実制御/実seedは渡さず、公開された過去bidから追従する。飢饉は2round後にfood_yield=0へ、景品変更は初回後に次景品10→3へ変わる。変更前に予定を知らせない。戦闘は既存3v3ルール上で各陣営1体のみ生存した限定配置、相手は初回guard→射撃/装填。チーム共同計画や大量NPCの新しい強度実証ではない。

## 実際の有限期間の目的代理値

資源は実際のstock+science+cultureの増分/100、競りは獲得点/30、戦闘は既存eliminate potentialの増分/2。建物の存在を回収済み所得と加点しない。資源の研究/記念碑/軍事拡張で資産を消費すると、この回収量だけは下がり得る。人格の主義・欲求や勝利条件への進展を含む総合的な正しさのラベルではない。

## 得たもの

共通flow_rollout.pyはゲーム得点を内蔵せず、観測context・実ルールによるモデル遷移・終局判定をadapterから受け取る。全合法初手に対して同じ人格/主義・仮のneed/mode/intentを保持した最大8一貫経路を作り、既存intertemporal.forecast→DecisionLoopへ渡せる。人格入力/元盤面を変えず、分岐の仮想結果も実経験へ学習しない。

競りの公開8点→10点/予算6では、steady/careは初回bid0で温存後、再判断でbid4を選び10点を実際に獲得。growth/egoは初回bid3の8点を取る。温存そのものを目的にせず回収まで進むことを確認した。同時に、後で価値が3点へ落ちた条件では温存した2人格の最終点が3に落ちた。未観測の改変まで予知する能力は主張しない。相手のbid変化条件では公開後に後続bidが6へ変化し、固定された対策にしがみつかない。

次の予測行動と実際の次の選択の不一致率（各エピソードの率を平均）は、資源scripted1.000→persona0.124、競り0.500→0.125、戦闘0.328→0.270。これは状態変化/RNG/本人の再計画を含む診断で、因果的な誤予測率や改善の合格基準ではない。特にscriptedの資源モデルはwaitを予測するので不一致が多い。

## 制限・不採用にしたもの

予測と行動の一致率だけで賢さを認定することを捨てた。資源回収量はscripted対照に対して3組改善/8組悪化。ただし勝利条件への最終進捗の合計は7.0655→7.7595、即時対照6.7726で、3方式とも資源勝利0/16だった。実際の資源不足はreflex/scripted各4単位からpersona0へ減った。消費を伴う目的前進と無駄な浪費を資産量一つで混同してはいけない。目的代理値と実際の勝利条件、人格的な譲歩を同時に評価する必要がある。

戦闘はreflexで生存22/32・本人勝利6/32、scriptedで生存23/32・勝利7/32、personaで生存26/32・勝利4/32。potential平均や生存だけを見ればよく見えるが、撃破目的の達成は減った。personaの移動列にA→B→Aの戻りが8回（対照0）あり、退避後の往復を要調査として残す。戻り自体は不合理の証明ではないが、無意味な停滞を避ける要求を満たしたとはできない。2個の実seedで4人格を反復した小標本なので、一般勝率の推定とはしない。

このため標準Policy/Population/既存plannerを置換しない。任意の共通rollout部品と診断として保持する。人格を同じ得点へ揃えたり、固定の完遂命令で失敗計画へ拘束したり、今回の結果を見て人格係数を調整して同じ条件で成功扱いすることはしていない。予測継続は同じ人格の即時判断で、実際の未来の時間評価・相手学習・進捗監視まで再帰的に再現する自己モデルではない。

## 次に解くべき急所

準備を採用する根拠を、実際の勝利/目的の達成、人格による許容可能な譲歩、必要な中間成果に分けて検査する。期限内の勝ち/引分/負けと未完了potentialを区別し、生存だけで撃破目的を達成したと扱わない。退避や準備は戻る条件・回収の観測と組にして、状況変更で撤回すべき場合を残したまま無意味な往復/延期を検出する。今回の12配置は開発条件として固定し、次候補は別条件/seedで検査する。期間を無制限に延ばすことは解決策にしない。

## 検証・再現

事前条件と全reflex/*.py hashをpreregister.jsonに保存してから実行し、終了時に源一致を確認。評価中の再調整なし。ローカルの793実遷移を別のルール再生スクリプトで照合し、24公開状態変更・25本人死亡遷移、全目的増分・組比較・副指標を再集計した。初期検証で非公開イベント条件をscope識別子へ含めていたため、観測前のmode乱数に影響する余地を発見した。修正前の源/結果はローカルclosed_loop_payback_pre_scope_fixとbackups/payback-before-observation-scope-fix.zipへ保全し、公開数値に使わない。scopeを初期の公開状態だけから生成するよう修正し、未発生の飢饉/景品変更/相手変更の条件で全contextが一致する検査を追加した。新しい事前hashを保存して192エピソードを実行し直した。人格係数・評価係数・条件/seedの選別はしていない。

10追加テストは入力保全、人格改変拒否、仮の意図の継承、非終局の未知未来を隠さないこと、終了後所得ゼロ、情報非先読み、競りの実回収を確認。全556テスト成功、任意麻雀14件skip。

再実行: python -m reflex.cli payback-cycle --output FRESH_ROOT。FRESH_ROOT/closed_loop_paybackへ出力し、既存の凍結出力の上書きは拒否する。私的な全実軌跡を持つ環境では python tools/audit_payback_cycle.py FRESH_ROOT/closed_loop_payback。公開は集計/事前条件/本報告だけ。共有実ルール、core/runtime/judgment/decision_loop/deliberationは基準611e364から変更しない。
