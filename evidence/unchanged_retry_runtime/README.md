# 全期間同じ経路になる継続案の再利用

公開目的が開始値を一度も上回らないモデル内経路では、利益が出るまで反復する案と、全期間反復する元の案が同じになる。元の案を計算する際に、一度でも終了条件に達したかを記録し、達しなかった場合は全経路・効果・本人の学習状態を独立コピーで再利用する。最後の値だけを見て同じと決めない。途中で利益を得てから元へ戻る場合には、この省略を適用しない。

既存のモデル関数の純粋性を前提とする。別の予測や別の人物の履歴を借りず、同じ判断呼出内の同じ根・応答・予測乱数・継続方針だけを対象にする。論理手数と全候補は維持し、省略した実計算は既存の `reused_steps` に数える。ゲーム名、行動名、利得の補正係数は使わない。

4分野と3準備課題の計7条件で、予測・全経路・将来の本人・実選択が修正前と一致した。計算回数だけを比較から分離した。対応CPU時間の合計は28.765625秒から25.296875秒へ減った。既に公開していた96手分の実経験を持つ本人についても、H32・3標本で全出力が一致した。その選択後の1実遷移・実学習・保存復元も一致した。ここではCPU時間が195.40625秒から183.484375秒だった。

経過時間は同時実行中のPCの割当にも左右され、この対応測定では228.20秒から239.79秒だった。全条件の待ち時間が同じ割合で短縮するという保証ではない。計算の省略自体と、忙しいPCでの経過時間は区別する。

関連25テストが通過した。利益を一度得てから開始値へ戻る反例、共通の継続案を複数の根で使う設定、全途中記録、独立コピー、人格・欲求と実学習を含む。リポジトリ全件の新規回帰実行ではない。全根拠は [verification.json](verification.json) と `verification_data.zip`、固定ソースは `source.zip`。

実行中の元の目的評価接続・新しい利益回収候補の世界比較には途中適用しない。これは計算結果の同等性の確認であり、人格AIの長期成績の改善、独立確認の合格、本採用を意味しない。
