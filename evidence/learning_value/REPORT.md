# 学びによって後の選択が変わる価値

2026-10-14。**宣言した有限モデルで、将来の学びを計画に入れる共通経路を実装し、通しの判断改善を確認した。** 固定した人格は維持する。全般的な賢さ・未知の敵への適応・人間水準の完成とは扱わない。

## 得たものと手放したもの

得たのは「情報を得たら嬉しい」という加点ではなく、**結果を見て次の手を変えられるから、今この手を選ぶ**仕組み。観測できる結果をまとめて仮説を更新し、同じ本人が次を選ぶ。調査する、行動しながら学ぶ、知っていることは調べ直さない、を別の専用ルールにせず比較する。

手放したのは、情報行動への小さな開放性加点と、調査費用を欲求・主義への損失に計上しない検証側の不均衡。同じ資産の増減を同じ意味へ揃えた。また、「短い探索の先を反射で試せば十分」という採用案は捨てた。4条件で目的値が悪化したため、短い方式を既定にしない。

**採用するのは任意の仮説・観測接続。** 既存の反射、人格係数、主義への固執の強さ、目的の許容幅は変更しない。一般の先読みを無条件に置き換えるものではない。

## 比較したもの

全方式が、実際の行動後には同じ公開情報で仮説を更新する。

- `myopic`：一手だけを評価する。次の実行時には学び直せる。
- `frozen`：終局まで読むが、探索内では今後の観測による仮説更新を止める。実行時には更新する。
- `adaptive`：探索内でも観測による更新と、その後の本人の選択を評価する。
- `tail`：一手の探索＋8シナリオの本人の反射継続。仮説は更新するが、将来も探索する本人との違いは残る。別の補完試験のみ。

目的値の比較は、モデルの全分岐で実際の方策を評価した**期待値**。同じ条件で32個の独立した実行乱数も使い、隠れたタイプを最初に選んで、その後の変化と公開結果を実行した。実際のタイプは判断器へ渡さない。

目的のみを最大化する別の全列挙も比較上限として計算し、人格方策がそれを不当に超えていないことを確認した。これは同じモデルに対する上限で、未知の実世界での正解ではない。

確認条件の `adaptive / frozen` を分けると、資源4改善・12同等、戦闘8改善・8同等、賭け4改善・12同等、オークション16同等。**オークションで将来の学びを入れた追加利益は示せなかった。** 一手評価との差を、すべて学習の効果へ数えない。

対象は各ゲーム4設定×4人格などの相関した小さい条件群。設定は情報精度、費用、時間制限、隠れた状態の変化を含むが、信号や調査費用のないオークションには一部の操作が効かない。64条件を64個の独立した未知ゲームの証拠とは扱わない。確認の設定は初回試験前に固定したが、費用修正後には同じ設定を再利用しているため、最終版に対する完全な未使用ホールドアウトではない。

主結果は**352方策評価・11,264実行・33,437実行判断**。全実行を、封じた隠れた状態・乱数・行動列から再生して照合した。反復数を独立した汎化条件へ水増ししない。過去の未修正版・失敗した実行はこの分母に含めない。

## 具体的な判断

- 体力が少ない戦闘では、更新を先読みに入れない人格は攻撃または防御から始めた。更新を含む本人は、敵の型を探ってから対応する攻撃を選んだ。この小さい既知モデルでは成功確率が50%から90%へ改善した。実ゲームや人間相手の勝率ではない。
- 資源では、安定・協力志向も、小さい確実な取引だけから、設備を作って収量を見て、その結果で残りの手段を変える方へ動いた。専用の「学習手」への報酬ではなく、生産行動から得た情報を使う例。
- 修正前の賭けでは、型の確率が約89.5%まで絞れた局面で調査を選び、小さい目的損が出た。[選択の採点](tradeoff_diagnostic.json)を確認すると、調査費用を欲求・主義側へ同じように引かない不均衡があった。調査費用と損失の意味を揃え、情報行動の性格加点を外して再試験した最終版では、adaptive の目的損は今回の条件から消えた。どちらの修正だけが効いたかは分離していない。

最終版の全実行では、変化のないモデルですでに仮説が確定している状態の調査は0回。初手が人格間で異なる条件も残った。ただし、性格値が固定され、手段が分かれることは、人格の魅力や心理学的妥当性の証明ではない。

## 何を実装したか

`BeliefKernel` は仮説ごとの条件付き結果を、本人が区別できる観測ごとに合流してから事後確率を計算する。隠れたタイプごとに別の手を選ばせる「知らないはずの正体を知っている」探索を避ける。同じ公開イベントに合流した未来の本人は、一つの知識状態から選ぶ。

未来の知識状態は複製で、本人の実経験を更新しない。実行時は同じ公開結果の更新式を使う。モデル・観測者を区別した保存復元、非公開状態を渡さない契約、モデル外の観測への明示的な辞退を設けた。詳細は [接続契約](../../docs/LEARNING_VALUE.md)。

全分岐・終局までの adaptive では、予測した目的値と、その先でも同じ本人が判断した期待値のずれは最大約 `1.11e-16`。これは小さい正しい有限モデルと一致する計画期間での検査であり、途中打切りやモデル違いまで解消していない。

複数分岐を合流すると、浮動小数点の和が1をわずかに超え、既存の範囲検査で止まるケースも見つかった。観測確率を正規化し、目的値は境界から `1e-12` 以内の丸め誤差だけを補正した。大きい不正な値を隠す変更ではない。

## ゲームをまたぐ範囲と残る急所

オークションは既存の3人用 `contests.settle` を利用。他の3系統は新しい、最大4手の自作診断ゲームである。旧8系統の大きなゲームすべてで強くなったとは主張しない。旧8系統・4人格・2設定の64局面では、既知仮説一つへ埋め込んだとき、従来の選択・本人の状態・結果分布が一致した。これは**接続の同値性**で、強さや実観測の十分な対応範囲の検証とは別。

短い探索への置換では、資源3条件、オークション1条件で frozen より悪化。情報更新を正しく入れても、反射だけで進む未来と、実際には再び考える未来は同じにならない。ここは前回から続く未解決で、標本数や係数を少し増やしただけで解決したことにはしない。

また、仮説や尤度をゲーム側が用意する必要がある。モデルにない相手の変化、自動的な仮説の生成、既存の主観的な思い込みとの合成は未完。公開性を満たすルールモデルなしにコアだけを投入すれば学習できる、という段階ではない。

今回の改善活動全体は停滞していない。有限モデルで学習の利益を計画へ反映するところは成立した。一方、**短い探索へ圧縮しても同じ賢さを保つ部分は未解決**。その未完成を、完成した有限モデル側の成績で覆い隠さない。
