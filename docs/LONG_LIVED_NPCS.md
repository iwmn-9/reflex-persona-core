# 長く暮らすNPCの比較

4〜8人が320ターン同じ世界で動く。短い局面の改善が、経験・関係・欲求を持つ住人としてつながっているかを調べる。全機能を有効にした万能構成の認定ではない。結果・採否は [検証報告](../evidence/long_lived/REPORT.md) を正本とする。

## 接続したもの

`EncounterWorld` の資源交換・共同警戒、既存4人格、有限優先の `Policy`、`WithdrawalSocialPopulation`、過去8手の公開行動予測。協力・横取り・再接触を台本にしない。固定性格・価値観を維持し、体力・活動力・備蓄に応じた欲求と相手別の関係記憶を更新する。個々の判断は同時に確定してから解決する。

所属・成長・承認の欲求はこの接続では定数。自主的な目標の作成・交換、包括的な感情更新、交渉、将来の協力関係を読む計画は接続していない。「全部入りNPC」「長期計画の実証」と呼ばない。

## 対照

| 構成 | 使用するもの |
|---|---|
| amnesic | 同じ人格・現在の欲求・直前の判断状態。相手の行動履歴と関係経験を判断へ戻さない |
| prediction | 公開された過去の相手行動から予測する。関係による好悪の加点はない |
| social | 上記に、好意・中立・警戒と相手別の経験を接続した既存方式 |
| net_effects | socialと同じ人物・記憶。生理・安全の効果を実際の一手後の不足量の差に置き換える診断候補 |
| material_greedy | 同じ合法手と公開予測で、直後の資源獲得だけを最大化する簡単な対照 |

最後は一般的なUtility AI全般の代表でも、GOAP・PsychSimの代替実装でもない。手順を準備する能力や長期の生存を最適化しないので、これに勝つだけでは既存AIより優れると主張しない。

`net_effects` はゲーム名・人格・手の名前に応じた採点補正を加えない。両ルールに同じ `after_action` を使い、回復の上限・消耗・維持費を含む実状態から、既存の不足量の変化を求める。旧入力は健康の回復分だけを安全へ直接渡し、維持費や健康の0〜8と不足量の0〜1の単位差を十分反映していなかった。入力を正したことと、長期の判断力が改善したことは別に判定する。実ルールと旧比較の判断は維持する。

## 同じ局面での経験の除去

socialとnet_effectsの16ターンごとに、実行前の本人を複製する。人格・欲求・盤面・個体乱数・直前の判断状態は保ち、相手の履歴と関係記憶だけを取り除いた選択と比較する。複製の結果は本物の記憶へ戻さない。

実際の全員の選択が確定してから、「自分だけ複製の手を選んだ場合」を同じ環境乱数で採点する。相手の今回の選択を知るのは検査器だけ。これは一手の物質的な得失であり、将来の関係利益、主義のための支払い、長期最適性の正解ではない。後半の生存者だけの良い成績を、全員が賢く成長した証拠にしない。

## 再現

```sh
python -m tools.long_lived_npcs --output FRESH_LONG --seed-start 91100 --seeds 8
python -m tools.audit_long_lived_npcs --root FRESH_LONG
python -m unittest discover -s tests -p test_long_lived_npcs.py -v
```

出力先は未作成のディレクトリを指定する。登録、実行ソースの実バイト、各世界の圧縮軌跡、集計を保存する。検査器は全実遷移・相手別記憶・選択時の関係評価・反実仮想の得失を再生し、さらに12世界の全判断を再実行する。人数分を独立な試合数に数えない。開発の2乱数列と確認の8乱数列を分け、係数を確認結果へ合わせない。
