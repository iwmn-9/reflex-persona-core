# 既存の取り組みとの関係

2026-10-04の一次資料確認。設計説明の確認と、実装を実行して能力を検証することは区別する。以下のツールは今回導入/実行していない。

|取り組み|確認できた近さ|採用判断への注意|
|---|---|---|
|[Utility AI / GDC](https://www.gdcvault.com/play/1012410/Improving-AI-Decision-Modeling-Through)|効用、応答曲線、個体の分布、重み付き選択を用いる判断。数値で複数の関心を統合する系譜。|人格的な選択と、オンライン学習の正しさは別の課題。|
|[CognitionAI / Cognitio](https://github.com/JuliGommz/CognitionAI)|作者のREADMEではUnity/C#、45特性、感情評価/認知評価/価値統合、動機/目標、固定設定と実行状態の分離、複雑さの段階制御。|公開コードだが作者許可なしの利用/派生を禁じるライセンス。認知/神経科学の名称を使う設計説明は、その実装の科学的妥当性の証明ではない。|
|[adaptive-ai-games](https://github.com/shreymusician/adaptive-ai-games)|作者の設計目標は、観測のみのプレイヤー傾向学習、人格、記憶、戦略と意思決定の分離、能力のゲタを使わない公平性。|現READMEは汎用AIエンジンのモジュールをPhase 1の構成骨組みと明記。アーカイブされた試作ゲームと汎用エンジンの完成を混同しない。|
|[Soar RL](https://soar.eecs.umich.edu/soar_manual/05_ReinforcementLearning/) / [記憶](https://soar.eecs.umich.edu/soar_manual/07_EpisodicMemory/)|報酬による操作選択の更新、経験の保存と検索を持つ認知アーキテクチャ。|人格NPC用の差し込みライブラリそのものではない。今の高速バッチコアとの速度比較は未実施。|
|[River ADWIN](https://riverml.xyz/dev/api/drift/ADWIN/)|観測系列の変化を検出し、変化前の窓を外す。古い見込みが通用しなくなった場合の検出候補。|仮説の真偽や人格的目的を判断する装置ではない。ノイズによる誤検知、検出遅延、必要標本、適用条件をゲームで検証する必要がある。|

今回の位置づけは、これらと無関係な新発明ではなく、人格/欲求/有限価値を持つ共有効用コアと、観測済み経験、有限予算の読み、異なるゲーム接続の実行検査をまとめる実験プロジェクト。特に目的を損なう対策の過剰適用、誤った仮説の採用/撤回、目的一貫性と合理的な損の区別を検証対象とする。既存の全ツールが未解決であるという主張はしない。
