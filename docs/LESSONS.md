# 失敗から残す教訓

安定版後の候補は未採用。

| 試したこと | 分かったこと | 次に確認すること |
| --- | --- | --- |
| 標本の層化・3本から8本への増加 | 長期利益の悪化が残った | 標本の揺れと予測モデルの誤りを分ける |
| 現在の世界が続くという仮定 | 長期利益の採用基準に届かなかった | 世界の変化後に予測と判断が回復するか |
| 予測精度の改善 | 誤差が減っても準備と長期利益が悪化した | 予測値が行動・準備時期へどう影響したか |
| 将来の本人と実行時の判断を揃える | 整合しても長期損は残った | 継続方針と将来価値を別に確かめる |
| 増分が出た時点で読みを止める | 背景収入で止まり、準備の成果を見逃した | 行動による増分と背景収入を分ける |
| 通常行動の期待値と準備成果を比較する | 新規の準備診断14条件を改善。将来の1手目的評価は不要だった | 同じH32経路で世界比較する。機構診断をゲーム横断の成功と扱わない |
| 選ばなかった分岐の結果で準備を終える | 終了判断に本人が見えない情報が入る場合がある | 開始時の期待値と現在の公開観測だけで切り替える |
| 実行費の削減・監視の追加 | 一部は速くなったが、判断品質の改善とは別 | 目標への効果がある作業だけ行う |

単純な固定32手は採用基準を通った。複雑な仕組みは、それで解けない原因が分かった時だけ検討する。
人格係数やゲーム専用の加点で損を隠さない。
不要な生ログ・途中結果・重複コピーは処分する。安定版と必要なテスト・採用根拠は残す。
