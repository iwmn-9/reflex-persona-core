# 失敗から残す教訓

- 単純な確率環境の合格は、複数NPCの知性や人間らしさの証明にならない。旧長期試験は再開しない。
- 人格係数の保存と、人格が分かる行動は別。実行リプレイで確認する。
- 全員の行動を一つの仮説へ押し込むと、個体別の学習材料を失う。全外れを無理に正解扱いしない。
- 予測誤差の減少、試走中の学習、長い読みだけでは実利益の改善を保証しない。実行結果で比較する。
- 行動名への加点は無益な繰返しを生む。ゲーム側は実際の効果と準備の意味を渡し、共通コアは人格に沿って選ぶ。
- 協調は本人たちの同意で成立させる。全員の効用合計で誰かを従わせない。現在の合意を永久協力と扱わない。
- 対戦相手も変更した自己対戦の平均値を、強さの向上と呼ばない。勝敗・本人の価値・代理評価を区別する。
- 速度・監視・検査件数は知性の成果ではない。詳細は次の改善に必要な範囲だけ残す。

安定版v0.1.0と必要な入出力契約は保つ。現行方針は [ADOPTION.md](ADOPTION.md)。
