# 局面に応じた未来の本人

性格・主義を増やす前に、読みの中でもその本人が局面を見て判断する。現実の人格や経験は予測から更新しない。協調の結果として合理的な手が一致することは許し、違いそのものを報酬にしない。

`OwnerBranch` は、数値提案に参加した所有者の固定軸と本人の状態を分岐ごとにコピーする。候補の最初の手は、その候補を実行した意図・継続年齢として記録する。続く公開状態からゲームの context factory を呼び、同じ所有者・固定軸・次状態・進んだ時刻を検査して既存の有限優先 `Policy` を呼ぶ。他者の実際の私的記憶を登録するAPIは持たない。

未来の根では、元の反射判断から得た欲求モードと候補の意図を使う。外側の六手評価が返すモードと厳密には同一でない。未来の公開局面から欲求と経路は再評価するが、実際の外側の判断器を自己再帰させる部品ではない。予測を現実の経験として学習させない。

`conditional_forecast.forecast` は既存の戦闘・資源競争 adapter の現在候補・目的尺度・譲歩幅を維持し、未来の継続だけを入れ替える。

- `personal`: 各本人が毎手、残った体力・資源・盤面から反射判断する。共同の将来意図を強制しない。
- `exchange`: 本人の再判断後、最大8候補の一手評価で再交渉する。合意しなければ各人の反射判断へ戻る。現実の六手評価での再交渉とは異なる。
- `forecast_ensemble.combine`: 同じ所有者・観測・実根・目的・時間幅を持つ2～8モデルを合成する。個人的効果は等比の結果混合、目的は最悪モデルまたは平均を明示する。試験の `robust` は従来の戦術継続と `personal` の最悪目的。悪い結果を切り捨てない。等比は未知であることの設計上の仮定で、学習済みの正確さを意味しない。

ゲーム上の非参加者は、従来と同じ休止・独立戦術の有限仮説にとどめる。相手の実際の今の手・将来の方針・乱数列は読みへ渡さない。枝の記憶はその枝だけに残り、本体へ合流しない。実世界のプロフィール・状態は元の実行経路からだけ更新する。

1対1では、同じ世界の参加人数と建設到達量だけを変更する。ルール、判断契約、採点係数、性格は専用に調整しない。チーム戦の総目的が本人の目的になるので、あらゆる個人ゲームを網羅した試験ではない。

比較・採否は [conditional_continuation](../evidence/conditional_continuation/REPORT.md) を正本とする。通常経路の既定は維持する。再現は新しい出力先で行う。

```sh
python tools/run_conditional_continuation.py --root FRESH_STUDY --start 9840 --seeds 8 --stage confirmation --genres projects --modes bargain_uncertain bargain_personal bargain_robust
python tools/analyze_conditional_continuation.py --root FRESH_STUDY --replay
```

実試合の全手を別実装の世界台帳で照合し、凍結したソースから試合全体・判断・次状態・選択モデルを再実行する。勝敗の改善、本人の健康・成長、初手の人格編成差、選んだ根での予測誤差は別に集計する。予測誤差の比較は各方式の違う実軌跡に条件付くため、共通局面での純粋な予測能力比較とは扱わない。
