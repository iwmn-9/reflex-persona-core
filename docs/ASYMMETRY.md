# 能力・資源・参戦時期が異なる人物の検証

能力と立場は人格と別の入力。ゲーム側が現在の合法手、消費できる資源、能力による効果、目的、世界の期限を提供し、既存の人格付き機会評価と予測更新を接続する。共通コアに「弱者なら賭ける」「強者なら守る」といった分類や行動加点を入れない。結果・得失の正本は [検証報告](../evidence/asymmetry/REPORT.md)。

## 実行経路

`tools/asymmetric_games.py` は既存 `OpenGame` の観測と `ClosedLoop` 接続を再利用する診断アダプター。共通 `AdaptiveOpportunity`、`OpportunityGraph`、`EventLearner`、`Policy` は変更しない。`OpenOpportunities.continuation` は、実行と参照診断が同じ人格投影を使うために既存処理を取り出したもの。

能力、所持資源、現在の盤面、世界時刻は公開状態へ保存する。状態の射影で能力差を落とさず、別の能力で作った評価を流用しない。資金・エネルギーが足りない手、所有していない手段は合法集合に入らない。これはゲーム側のルールであり、判断器が勝率を見て特定の手を禁止する補正ではない。

性格4種、主義、固執度0.5、目的許容幅0.15、予測器8/32/128観測を固定する。欲求は既存の固定入力。現在の能力を知っている前提であり、能力の発見・偽装・故障の推定は含まない。

## ルールと割当

- 競り：3人の封印入札。手持ち資金、入札上限、偶数入札のみで落札代金が1安くなる特化能力を変える。先頭の公開賞品から順に進み、落札者だけが支払う。最終の得点＋残資金0.25で順位を決める。
- 資源：手持ち資金、3生産手段の収率と利用資格を変える。交易、生産、設備投資がある。相手側の生産も進む。終局の現金＋設備価値を競う。
- 戦闘：エネルギー、使える攻撃、威力が異なる。防御で体力・エネルギーを回復し、位置取りで次の攻撃を確実にできる。相手の構えへの攻撃が外れると被弾する。撃破で勝ち、倒されれば負け、両者生存の時間切れは引き分け。
- 賭け：所持金、選べる賭け先、配当が異なる。相手も公開された手順で賭ける。資金を保持する選択もでき、終局所持金を競う。

標準、資源不足、資源余裕、能力制限、高能力、特化、途中参戦、参戦前から観戦の8割当。割当名は実験側だけが保持し、本人の入力に強者・弱者ラベルを渡さない。いずれも自作の短い診断ルールで、既存商用ゲームの再現ではない。相手は確率的な条件付き行動であり、複数の人格NPCが交渉する実験ではない。

世界の期限は4手。途中参戦は相手だけで2手が実際に進んだ後に入る。得点・資金・設備や防備を初期化せず、残り2手で判断する。観戦ありの人物だけが先行2手の公開イベントを予測記憶へ取り込む。未参加期間の自分の行動・報酬・感情を捏造しない。ゲーム内の消費資源は各対戦の開始配置へ戻すが、6対戦の間は予測記憶を持ち越す。

## 比較と診断の境界

実行するのは、本人の現在予測で終局まで評価する `live` と、同じ人格で即時効用を選ぶ `reflex`。両者の開始盤面・先行履歴・乱数の対応を揃え、実際に起きた公開結果だけをそれぞれ学ぶ。行動が変わると経験も変わるため、差を探索深さだけの効果とはしない。

診断用には、本当の確率を知る目的最優先と、同じ人格で本当の確率を知る継続も計算する。これらは本人へ渡さない。目的上の到達可能性、人格のための交換、誤予測による差を区別するための条件付き参照である。

一手の機会損失は、同じ盤面で以後を目的最優先にしたときの候補差。継続方策の評価は、現在の予測を固定した本人の計画を本当の確率で再評価する。以後の学び直しまで含む実行価値とは区別する。勝てない配置で引き分けを選ぶことを失敗とせず、実際の勝敗と到達可能な目的値を併記する。

同じ盤面の人格差、同じ人格の割当差も集計する。ただし行動が違った件数だけで賢さや人格の豊かさの完成とは判定しない。合法手が減って変わっただけの場合も含む。

## 再現

```sh
python -m unittest tests.test_asymmetry -v
python tools/run_asymmetry.py --stage development --root FRESH_DEV --workers 4
python tools/run_asymmetry.py --stage holdout --root FRESH_HOLDOUT --workers 4
python tools/analyze_asymmetry.py --root FRESH_DEV
python tools/analyze_asymmetry.py --root FRESH_HOLDOUT
```

毎回新しい出力先を使う。ソースと条件を凍結してから開始し、全実観測と更新後の記憶を再生する。最初の予備版は戦闘を時間切れ時HPの順位で採点していたため、能力差を試しにくかった。敵の撃破と引き分けに分けたv2を主比較に使用し、予備版を主比較に足さない。戦闘の検証ルールの修正であって、人格や学習係数を結果へ合わせた修正ではない。

ゲームごとの観測・合法手・効果・目的の宣言は依然として必要。この実証から、未知のゲームへの自動移植、長期社会関係、無期限世界、能力の未知変化への安定性は主張しない。
