# 実際の本人による先読みの接続

`reflex.policy_rollout.evaluate_policy` は、既存の `monte_carlo.evaluate_actions` に、根ごとの未圧縮終局標本を返す共通部品を足す。新しい人格評価器やゲーム報酬は作らない。標本の一巡が途中で切れたら、その一巡を全根で捨て、最低標本数に届かなければ元の判断へ戻す。外側のノード予算には、コールバック内部の探索費用を含めない。

## adapterの責任

- `begin_trial`：仮想の本人状態・記憶を複製する。本人の性格と主義は固定し、実記憶や実乱数を変更しない。
- `choose`：仮想の公開観測と本人が所有する状態を、その個体の既存制御器へ渡す。次の手でも同じ制御器が再判断する。欲求や感情を扱うゲームでは、その仮想状態も観測に合わせて更新する。新しい根の改善器を再帰的に呼ぶことは、今回の構成では行わない。
- `sample`／`step`：ゲームの合法遷移を進める。未知の世界と相手仮説を各根で対応させ、偶然の経路と意思決定の時計を分ける。
- `evaluate`：本人の目的と人格が参照する終局結果を返す。推測した未来を、観測済みの実経験として学習させない。

相手の本当の性格、非公開の記憶、実際の未来イベントは入力にしない。相手モデルのために仮想人格を置く場合も、本人が観測した情報からの仮説であることを記録する。ゲームの隠れた実状態は、実対局の駆動や事後診断だけに使う。

盤面は各遷移で別の値を返すか、試行ごとに複製した私有値を使う。実盤面や他の根を変更しない。終局の効果も、過去の標本を書き換えない新しい値として返す。二つの接続例は、盤面に不変のdataclassとtupleを使う。

正しい本人継続を読むことと、相手・世界の予測が正しいことは別である。Monte Carlo標準誤差は有限標本の誤差であり、仮説そのものの誤りを保証しない。本人の期待効用で選び直しても、全般的な改善や人間水準を約束するものではない。

## 接続済みの二つの例

`thanks_policy_rollout.decide` は4人のNo Thanks!の公開取引台帳へ接続する。未来の本人は元の `strong_table.decide` を同予算・同じ本人seed・複製状態で呼ぶ。各仮想の公開行動で本人の相手記憶も更新する。公開していない実山札や本当の相手人格は渡さない。`future_seed='resampled'` は、同じ算法だが本人seedを引き直す明示的な比較用の近似である。

相手継続には二つの任意設定がある。`reactive` は既存の公開学習による12行動仮説。`searched` はobjectiveと4人格の、同予算で再判断する5仮説を等確率で置く。後者の相手私有状態は新しい仮想の状態であり、実相手の過去を復元できたとは扱わない。旧12仮説の学習重みを、意味の異なる新5仮説へ流用しない。

`connect_policy_rollout.decide` は公開のConnect Fourへ接続する。本人は有限主義の `Policy` と既存 `SHORT` 予算で毎手再判断する。この新基線を、過去の別のboard試験の基線と混同しない。相手は公開盤面での `minimax2`、`minimax4`、または両者を試行ごとに等確率で仮定する `mixture`。混合仮説は各根で同じ種類を使い、一つの継続中は種類を維持する。実際の相手のラベルを予測器へ渡さない。オンラインの強さ識別はまだない。

共通部品を二つの異なるゲームへ接続したことと、未知ゲームへ自動で接続できること、全ゲームで強くなったことは区別する。戦闘・オークション・複数資源ゲームへ、この追加部品の効果はまだ検証していない。

## 任意経路としての使い方

No Thanks!では `strong_table.play(..., controller=...)` が任意の接続点になる。無指定は元の制御器を使う。Connect Fourでは元の `incumbent` と追加の `decide` を分ける。主な対戦は一人の一度の判断だけを追加器へ通し、以降は全員が元の制御器へ戻る。別の `public-continuous` 比較では、実際の本人が毎回追加器を使う。そこで予測している未来の本人は従来の制御器なので、実際の新制御器との自己一致は保証しない。全NPCの自動切替は行わない。

実行・得失・不採用条件は `evidence/policy_rollout/REPORT.md` を正本とする。性格・主義は動きにくい傾向、欲求・感情はリアルタイムの状態という設計を保つ。今回追加したのは継続評価であり、共通の感情更新器を実装したものではない。
