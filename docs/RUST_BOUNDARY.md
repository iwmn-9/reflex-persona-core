# Pythonで検証し、安定した完成単位をRustへ移す

Pythonを実験・審判・比較の正本として残す。Rustの対象は、小さくても用途に対して一まとまりの完成形になり、設計・振る舞い・境界がほぼ変わらなくなった実行単位。個別の比較に通ったことだけでは移植対象に昇格させない。

## 即時判断の境界

2026-10-24、[reflex-runtime](../rust/reflex-runtime/README.md) に全体の実行入口を追加した。
`GameSession<World>` が観測・複数NPCの判断・世界の実行・全員の反映・一体の保存復元を扱う。
採点は下記の即時判断v1へ委譲する。途中参加/退出、未実行、並列実行、古い判断案の拒否も
この層の責務。学習や長期判断の移植ではなく、安定した判断を世界へ接続する実装である。
契約の正本はcrateのREADME、実測は [統合検証](../evidence/rust_port/runtime/REPORT.md)。

`rust/reflex-immediate` は、ゲームが与える観測・欲求・候補・結果の見込みから、一人の通常判断を実行するcrate。人格・主義3方式、損失評価、慣れ、切替費用、有界補正、提供済みの相手予測の採否、近接候補の確率選択を含む。入力検証、純粋な判断案、実行済み状態の反映、人物に結び付いた保存復元までを一単位とする。[APIと使用例](../rust/reflex-immediate/README.md)。

Pythonの `Policy.choose` の、社会評価・`ReturnFrame` を指定しない経路が参照。候補の意味を推定するゲームアダプター、感情・関係記憶の更新、学習、相手モデルの生成、先読み、長期価値の換算は移さない。これらはPythonで改善を続ける。動的な欲求と結果予測は毎回の入力で受け取り、固定人格と混同しない。

2026-10-21の昇格確認は [実測と採否](../evidence/rust_port/immediate/REPORT.md) を正本とする。Windows/Linux x86-64、Rust 1.99.0、NumPy 2.3.5を比較対象とする。旧 `tools/rust_policy_probe.rs` の5,124判断一致は数値試作の結果として保存し、crateの完成証拠には流用しない。

採点は64bit浮動小数で、参照実装の二列の加算順序をスカラー演算で明示する。単純な逐次加算では、約1e-16の差でも同点付近の行動が変わったため。NumPyの内部実装を永続的な仕様とせず、この版の順序を固定する。未検証のCPU・参照ライブラリ版での同等性は追加確認が必要。Pythonの係数や選択基準は変更していない。

保存版は `reflex-immediate-v1`。意味を変える更新では版を分け、旧セーブを暗黙に読み替えない。世界側の保存と判断結果の反映を一体で確定する責務はゲーム側にある。通常のPython実行経路はRustへ切り替えない。

## 実装へ移す条件

移植の順番を部品名で固定せず、次の条件を満たす単位から選ぶ。

- 責務と入出力が定まり、その用途に必要な状態更新・入力検証・保存復元などを含めて使える。
- 異なる環境への接続と継続実行で振る舞いを確認し、主要な接続不良が残っていない。
- 次の研究で基本設計や契約を変える見込みが小さく、Python側を参照して互換性を検査できる。

全人格AIの完成を待つ必要はない。例えば通常判断の独立した完成単位が成立すれば先に移せるが、数式と乱数の一致だけで完成扱いにはしない。「ほぼ変わらない」は永久に修正しない約束ではなく、不具合修正や互換的な拡張は続ける。目的評価・学習・社会判断・探索など、構成を探っている領域の実験はPythonで続ける。

Rust化だけで賢さは増えない。大量NPC向けの配置・並列化・ゲームへの組込みを進めやすくする手段である。現状の大きな費用は状況評価や探索にもあるので、採点部の移植だけでゲーム全体が何倍速くなるとは言わない。

変更の採否は、同じ入力から同じ合法な選択と次状態が得られることをPythonとの比較で確認する。初期移植は64bit浮動小数、整数の桁あふれ規則、同点の順序、乱数の個体分離を保つ。32bit化やSIMD、並列化はその後の独立した変更として測る。

```sh
# Rustコンパイラーが入った環境。未作成の出力先を指定する。
python -m tools.verify_rust_policy_probe --output FRESH_RUST_PROBE
```

crateの検証は `cargo test --locked --manifest-path rust/Cargo.toml --workspace` と
`python tools/verify_rust_immediate.py --output FRESH_RUST_IMMEDIATE`、
`python tools/verify_rust_runtime.py --output FRESH_RUST_RUNTIME`。
C ABI、Python拡張、特定エンジンへの組込みは対象外。利用許諾の追加と公開レジストリへの配布も行わない。
