# 実観測による予測修正と終局評価

`reflex.adaptive_opportunities.AdaptiveOpportunity` は既存の `EventLearner`、公開機会グラフ、人格付き `ClosedLoop` を同じ予測時点で接続する任意部品。新しい人格モデルやゲーム別の補正係数は追加しない。結果・悪化例・採用範囲の正本は [検証報告](../evidence/adaptive_opportunities/REPORT.md)。

## 一回の判断と実観測の境界

1. 実際に得た公開観測から作った `AdaptiveState` を渡す。
2. `AdaptiveOpportunity(graph, kernel, state, owner, choose=..., chooser_id=...)` が現在の予測記憶を複製し、その予測で終局分布を再計算する。`choose` は将来も同じ人格で判断するための接続。
3. 同じオブジェクトを `ClosedLoop` の `transitions` と `frontier` に渡す。心理入力の意味を宣言する場合は、グラフ内の `persona_choices` と `ClosedLoop` の両方へ同じ `PreferenceBasis` を渡す。
4. 実行した一手の公開結果だけを元の `AdaptiveKernel.reveal` へ返す。次の判断では新しい記憶から作り直す。旧評価を更新後の記憶へ使うと例外になり、黙って異なる予測を混ぜない。

`action(state)` はグラフ内の選択、`evaluate(state, owner)` は終局分布。実行側の一手選択と `action` が一致することを検証する。別個体・別人格／方策、再構築済みグラフ、未評価の局面、異なる予測記憶は拒否する。保存済みの学習状態から同じ計算を復元できる。

元の学習器は、結果を覚える**前**の予測成績に基づいて、短期・中期・長期と条件付き予測の重みを変える。使われなくなった予測器にも少量の重みを残し、再び当たるようになれば復帰できる。古い傾向の見切りと新しい傾向への修正はこの既存機構が担う。一回の外れを変化の確定証拠とはしない。

今回の接続で `HypothesisTracker`、`EvidenceGate`、手順列を一箇所ずつ直す `PlanRepair` を直列に重ねることはしない。これらは別の経路で使う部品。ここでは既存の予測混合を更新し、目的・人格を維持したまま残る合法な機会を再評価して手段を変更する。目的達成に不要な手順の同一性や、切替を避けるためだけの罰は追加しない。

## 明示的な省略

**一回の長期評価の内部では将来の学習を省略する。** 途中の想像上の結果で最初の一手だけ記憶を更新し、その先に更新前の評価をつなぐ混合も避ける。実世界では観測後に更新し、毎手評価し直す。したがって情報獲得の将来価値を含む完全な学習計画ではない。

心理状態の十分性はアダプターの責任。今回の4診断では固定欲求・切替費用0・一定の親しみ係数を使い、未来のmodeを共有できる。追加の関係記憶や動く欲求などを無条件に組み込まない。予測器の重みを真の原因の確率や校正済みの信用度として扱わない。主義や頑固さの係数を学習器が変更することもない。

## 検証の読み方

比較は予測更新を止めた基準、長期記憶のみ、既存の短期／長期併用、併用＋従来の代理点。人格係数・主義・固執度・目的許容幅は同じ。公開履歴による準備を共有し、実際の手に対して起きた公開結果だけを覚える。

安定、ランダム、単発の外れ、持続する変化、復帰、緩やかな変化を分ける。予測誤差だけでなく、実行後の終局目的値、同じ盤面で更新前後の方針を比べた期待値を記録する。変更数が多いだけで悪いとせず、変更がなかっただけで安定した知能とも呼ばない。方針変更の期待値は本人に渡さない参照世界による診断であり、人格による目的上の妥協も含みうる。

準備の観測列は共通だが、実行中は選ぶ手によって訪れる盤面や観測条件が変わる。予測誤差の平均は各方式自身の軌跡上の値であり、完全に同じ観測列での予測精度だけの比較とは区別する。

競り・資源管理・戦闘・賭けは短い公開診断ルール。大規模な実ゲーム、人間との対戦、隠れたルール、社会記憶や感情が動く全構成への保証ではない。

```sh
python -m unittest tests.test_adaptive_opportunities -v
python tools/run_adaptive_opportunities.py --stage development --root FRESH_DEV --workers 4
python tools/run_adaptive_opportunities.py --stage holdout --root FRESH_HOLDOUT --workers 4
python tools/analyze_adaptive_opportunities.py --root FRESH_DEV
python tools/probe_adaptive_horizon.py --root FRESH_SIX_STEP --workers 2
```

新しい出力先を使う。開始前にソースと条件を固定し、エラーも残す。分析は全公開遷移・学習前予測・学習後記憶・終局点を再生する。過去の実験出力は上書きしない。
