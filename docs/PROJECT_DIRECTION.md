# 人格NPCの目標と開発方針

最終目標は、ゲームを替えても使える「その人物なりに合理的な判断」の土台。単なる最強CPU、勝率を揃えた性格集、心理パラメータの細密な再現を目指さない。固定した人物の軸を持ち、欲求・感情・経験によって手段を変え、協力・エゴ・妥協・攻略への対応からゲームの展開を作る。

この文書は現在の判断基準と優先順位の正本。各実験の数値・旧案・不採用理由はそれぞれの evidence に置く。全体診断は [foundation_audit](../evidence/foundation_audit/REPORT.md)、そこから着手した将来の本人と目的評価の検証は [closed_loop](../evidence/closed_loop/REPORT.md)。

## 守る七つの条件

1. **人物の軸**：性格と有限の主義・価値観はあまり動かさない。主義の強さと譲りにくさを分ける。本人のためになると理解して妥協することも、損をしてでも固執することも表現する。
2. **動く状態**：欲求・感情・経験は現在の判断へ同時に作用する。四つの心理層を直列に通す仕様ではない。欠測を失敗と覚えず、想像した経験を実体験へ混ぜない。
3. **最低限の賢さ**：人格のために払った損と、見込み違い・接続不良による損を区別する。無意味な停滞を避け、準備・維持・待ち合わせのための停止は残す。勝率の均等化で個性を消さない。
4. **公平な適応**：本人が知れる情報だけを使う。有利な方策を対策のためだけに捨てない。単発の不運、相手の変化、自分の計画変更を区別して学び直す。
5. **多数の独立した個体**：通常判断は数値バッチ、重い読みは任意。個体ごとの人格・記憶・乱数を混ぜない。今は速度より成立を優先するが、全NPCへ常時巨大探索を必須にはしない。
6. **ゲームをまたぐ境界**：ルール・合法手・知覚・目的・結果の意味はゲーム側。人格評価・採否・記憶の所有・判断の更新は共通側。ゲーム名や個別の手への補正をコアへ書かない。
7. **相手・住人としての面白さ**：癖が伝わり、読めるが永久にはめ続けられず、利害から葛藤や協力が生まれること。効かない心理の細部は省く。行動差や勝率だけで面白さを達成したとしない。

人間は目的と感触を伝える。軌跡の鑑定や心理係数の設計を人間へ丸投げせず、開発側が「癖・葛藤・状況変化への対応」を実行例から評価する。

## 全体を見直した判断

人格の表現、目的の評価、未来のモデル、実行と経験を分けた現在の大枠は維持する。全面再構築の根拠はまだない。一方、任意部品を増やし続けることを完成への進捗とは数えない。部品が存在すること、互いに接続できること、通しで判断が改善することを別々に判定する。

共通条件で反射、人格付き先読み、同一予測での目的優先、長い先読みを比較する診断から、将来の本人の再判断と目的の見積りを改修の中心に選んだ。小さな公開モデルでは最善の目的達成確率と、現在の制御器を毎手使った場合の達成確率を全分岐で求める。目的優先は比較役であり、人格NPCの置換案ではない。

将来の各公開局面でも同じ本人が残りを読んで選ぶ、条件付き探索を任意部品として実装した。公開確率を列挙できる場合は全分布を扱い、損失や人格の採点を平均結果に潰さない。終局まで見える条件で改善した一方、短い固定窓・少数標本・途中の代理評価では損も残った。固定窓の一律採用と全ゲームへの標準昇格は見送る。人格係数をいじって成績を合わせる方向は取らない。

調査中に見つけた「停滞解除を裏付けられず元の判断に戻る際、関係評価を落としていた」「物理的な効果が同じなら、関係上の価値が違っても高費用の候補を削っていた」という接続不良を修正した。新しい感情を追加せず、既に知っている相手への態度を候補の除外・復帰・読み・補完・学習案の比較にも渡す。これは賢さ全般を解決する改修とは分ける。

## 能力と接続の現在地

| 領域 | 接続・確認できているもの | まだ満たしていないもの |
| --- | --- | --- |
| 固定人格・価値 | 有限軸、欲求との同時採点、主義の固執度、バッチ個体分離 | 人間の心理尺度としての科学的校正、長期の人格らしさの実証 |
| 欲求・関係・感情 | 欲求更新、相手別の経験、好悪の省略、無益な報復を増やさない社会接続 | 共通の包括的感情更新器。追加の感情分類を先に増やさない |
| 即時学習・相手読み | 選んだ手の実結果、有限仮説、採用・撤回、既知条件付きルールで本人評価に沿う助言採点 | 未知の反応型の発見、変化した欲求へ過去の判断利益を移す基準 |
| 先読み | 共通の目的・人格採点、複製本人の再帰的な再判断、既知確率の全分布、有限の計画修正、実行後の予測採点 | 途中の代理評価の妥当性、有限標本・未知の相手モデルの誤り、遅延誤差から次の計画を良くする学習。正確な公開モデルでの一致を未知環境へ一般化しない |
| 停滞解除 | 準備と無根拠な停止の区別、目的改善の証拠がある代案だけを採用 | 改善証拠を求める監視と独立readerの併用は未対応。接続禁止を解除するだけでは直らない |
| チーム | 所属と合意の分離、独立案との譲歩比較、公開された仲間の行動学習 | 全員が実際に再交渉する継続の予測、長期の役割変更、強い協調相手への安定性 |
| ゲーム横断 | 複数ルールへ同じコアを接続、所有者・目的・情報境界の検査 | ルールだけから正しい評価器が自動生成されること、未知ゲームでの人間水準 |

単一の「全部入り推奨構成」はまだ認定していない。`DecisionLoop` は共通の実行窓口だが、任意機能を全て有効化しただけで品質が上がる保証はない。通常のコア、個別に有効性を確認した構成、研究候補を混同しない。

## 次の改修の優先順位と合否

**第一は、目的の評価と継続の見積り。** 本人の主義を弱める前に、選択肢の順位を間違えた箇所を直す。途中の代理値、先読みの打切り、有限標本、未来の本人の弱い行動、相手仮説の誤りを分ける。目的点を優先しても残る損は、心理係数の調整では解決したことにしない。予測の目盛りが粗く、本人に許した小さな妥協の幅を表せていない場合も検査する。既存の終局標本や全分岐比較を参照として、将来価値を予測する評価器・継続方策を検査する。学習器の種類は先に決め打ちしない。

条件付き探索によって「同じ公開モデル・残り区間・本人なら、予測内の再判断と実行が一致する」範囲を作れた。次に優先するのは打切り地点の価値とモデル誤差。正しい確率と終局までの読みを参照役に、短い読みの先の評価を独立な実結果へ校正する。深さを一律に増やすことや局面ごとの禁止手の追加で済ませない。

学習候補としては、平均値だけでなく結果分布を予測する [Distributional RL](https://proceedings.mlr.press/v70/bellemare17a/bellemare17a.pdf) を検討する。ただし同論文の実装は期待値で行動を選び、分布は環境の結果のばらつきであってモデルの信用そのものではない。人格ごとの危険の扱いと、未知モデルへの不確かさは別途必要になる。これは次の選定基準であり、今回その学習器を実装・採用した意味ではない。

報酬の好みを替えて経験を再利用する [Successor Features / GPI](https://arxiv.org/abs/1606.05312) も参考になるが、原論文の転移設定は環境の遷移が共通で報酬が変わる場合。違うゲームへの自動移植や、非線形な人格採点の保証へ読み替えない。同じゲームで人物の好みを替える能力と、ルールそのものが違う環境へ移す能力を分けて検証する。

**第二は、同じ本人による一連の実行。** 欲求・関係・進展監視・相手予測が通常、計画採用、辞退、復帰、保存復元、モデル内の本人で途切れないようにする。実結果から改訂する対象が、即時効果なのか、相手の反応なのか、宣言した時点の目的値なのかを揃える。予測採点と遅延の因果功績は分ける。無条件な全機能合成は採用しない。

**第三は、人格の伝わる展開。** 上の基盤を保ったうえで、警戒しても関係を完全に切らない、今は譲って回収する、仲間の利害を踏まえて役割を変える、といった場面を通しで観測する。専用の台本や意味のない失敗で面白さを足さない。

採否は、事前に固定した異なるルール・途中局面・人格で、目的の利益と損、主義のための支払い、停滞、情報の公平性を報告して決める。既に全勝の条件、同じ決定論的軌跡の再実行、同じ世界の複数NPCを独立標本として水増ししない。速度費用は当面の合否に使わない。全般的な賢さ、人間水準、面白さの完成は未達成。
