# 目的と制約

異なるゲームの対戦相手・住人に使える人格AIを作る。
同じルールと情報制約の下で、その人物なりに合理的に動き、経験から手段を変えられることを目指す。

- 性格と有限の主義・価値観を保つ。強さと固執を区別し、犠牲や妥協を許す。
- 欲求・感情・経験は変化し、判断へ同時に作用する。想像した経験を実記憶へ混ぜない。欠測を失敗と扱わない。
- 人格による損と判断ミスを分ける。勝率を均等化しない。無意味な停滞を避け、利益のある待機は残す。
- 本人が知れる情報だけで適応する。不運・相手の変化・自分の方針変更を区別する。有利なら対策のためだけに方針を捨てない。
- 個体ごとの人格・経験・乱数を分離する。通常判断と重い読みを分ける。今は速度より成立を優先する。
- ルール・合法手・観測・目的・結果の意味はゲーム側。共通コアへゲーム名や行動名による補正を入れない。
- 癖・葛藤・協力が生まれ、同じ攻略が永久に通じない相手を目指す。判断に効かない細部は省く。

人間は目的と感触を伝える。設計・実装・検証はAIが引き受ける。
実験の制御と集計はPython。計算部品と実対戦は研究用Rustでも実装する。安定版への採用と研究実装を分ける。
改修は既存の人格・学習・予測・再計画の接続と長期安定を優先し、新機能を増やさない。
原因を絞る診断から、必要な長期比較・独立確認へ進む。局所改善や回帰検査だけで採用しない。
登録条件・人格・乱数・対照を結果に合わせて替えず、採用基準を緩めない。途中を完走扱いにしない。
失敗の詳細保管は目的にしない。次の成功に必要な教訓を残す。
報告は目標への進展、得失、未確認事項に絞る。
