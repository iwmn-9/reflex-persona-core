# 人格NPCの目標と開発方針

最終目標は、ゲームを替えても使える「その人物なりに合理的な判断」の土台。単なる最強CPU、勝率を揃えた性格集、心理パラメータの細密な再現を目指さない。固定した人物の軸を持ち、欲求・感情・経験によって手段を変え、協力・エゴ・妥協・攻略への対応からゲームの展開を作る。

この文書は現在の判断基準と優先順位の正本。各実験の数値・旧案・不採用理由はそれぞれの evidence に置く。全体診断は [foundation_audit](../evidence/foundation_audit/REPORT.md)、将来の本人と目的評価は [closed_loop](../evidence/closed_loop/REPORT.md)、打切り地点の価値は [frontier_value](../evidence/frontier_value/REPORT.md)、学びによる将来の選択変更は [learning_value](../evidence/learning_value/REPORT.md)、既存仮説外の公開傾向の学習は [open_model](../evidence/open_model/REPORT.md)、残資源と将来の選択肢は [opportunity_graph](../evidence/opportunity_graph/REPORT.md)、人格の代償と代理評価の区別は [preference_basis](../evidence/preference_basis/REPORT.md)、実観測による修正と終局評価の接続は [adaptive_opportunities](../evidence/adaptive_opportunities/REPORT.md)。

## Python安定版の期限と範囲（2026-10-24合意）

目標日は **2026-11-03**、最終期限は **2026-11-07（日本時間）**。新しい判断機構の追加を止め、既存の人格・欲求・実経験の学習・相手予測・毎手の再計画を、一つの推奨構成として通しで使える状態にする。期限は検証や合否の省略理由にしない。研究全体の完成や未知ゲームでの人間水準までを、この版の達成として主張しない。

採用済み構成と研究候補を区別する。H32候補は凍結した独立40組と[登録済み基準](../evidence/long_horizon/continuation_selected_confirmation_acceptance.json)を完了・監査してから採否を決める。損失、未完了条件、人格差、費用も残す。既知局面や単体試験だけで昇格させず、悪化を別人格の調整で埋めない。途中の計算は凍結したソースで継続し、統合改修とは混ぜない。

安定版には、設定と入出力の契約、欠測と失敗時の更新、全状態の保存復元、ゲーム側の責任範囲、実際に配布したパッケージからの実行例を含める。将来予測の中だけで学んだ経験を本人へ混ぜない。復元時に人格・予測の前提・読みの設定を取り違えず、通し実行と同じ判断を続けられることを検査する。主要4系統の長期評価、独立確認、対応環境の回帰試験を必要条件とする。新たな修正が判断を変える場合は、その影響範囲に必要な独立確認を行う。

数値基準の正本は既存の登録書、リリース作業の状態は [安定版計画](../evidence/stable_release/plan.json)。合格前はバージョンを安定版へ上げない。期限までに既知の阻害事項を解消できなければ、成果・根拠・残る阻害事項を明示し、不合格のものを安定版として出さない。定期実行は再開しない。

## 守る七つの条件

1. **人物の軸**：性格と有限の主義・価値観はあまり動かさない。主義の強さと譲りにくさを分ける。本人のためになると理解して妥協することも、損をしてでも固執することも表現する。
2. **動く状態**：欲求・感情・経験は現在の判断へ同時に作用する。四つの心理層を直列に通す仕様ではない。欠測を失敗と覚えず、想像した経験を実体験へ混ぜない。
3. **最低限の賢さ**：人格のために払った損と、見込み違い・接続不良による損を区別する。無意味な停滞を避け、準備・維持・待ち合わせのための停止は残す。勝率の均等化で個性を消さない。
4. **公平な適応**：本人が知れる情報だけを使う。有利な方策を対策のためだけに捨てない。単発の不運、相手の変化、自分の計画変更を区別して学び直す。
5. **多数の独立した個体**：通常判断は数値バッチ、重い読みは任意。個体ごとの人格・記憶・乱数を混ぜない。今は速度より成立を優先するが、全NPCへ常時巨大探索を必須にはしない。
6. **ゲームをまたぐ境界**：ルール・合法手・知覚・目的・結果の意味はゲーム側。人格評価・採否・記憶の所有・判断の更新は共通側。ゲーム名や個別の手への補正をコアへ書かない。
7. **相手・住人としての面白さ**：癖が伝わり、読めるが永久にはめ続けられず、利害から葛藤や協力が生まれること。効かない心理の細部は省く。行動差や勝率だけで面白さを達成したとしない。

人間は目的と感触を伝える。軌跡の鑑定や心理係数の設計を人間へ丸投げせず、開発側が「癖・葛藤・状況変化への対応」を実行例から評価する。

## 全体を見直した判断

人格の表現、目的の評価、未来のモデル、実行と経験を分けた現在の大枠は維持する。全面再構築の根拠はまだない。一方、任意部品を増やし続けることを完成への進捗とは数えない。部品が存在すること、互いに接続できること、通しで判断が改善することを別々に判定する。

共通条件で反射、人格付き先読み、同一予測での目的優先、長い先読みを比較する診断から、将来の本人の再判断と目的の見積りを改修の中心に選んだ。小さな公開モデルでは最善の目的達成確率と、現在の制御器を毎手使った場合の達成確率を全分岐で求める。目的優先は比較役であり、人格NPCの置換案ではない。

将来の各公開局面でも同じ本人が残りを読んで選ぶ、条件付き探索を任意部品として実装した。公開確率を列挙できる場合は全分布を扱い、損失や人格の採点を平均結果に潰さない。終局まで見える条件で改善した一方、短い固定窓・少数標本・途中の代理評価では損も残った。固定窓の一律採用と全ゲームへの標準昇格は見送る。人格係数をいじって成績を合わせる方向は取らない。

調査中に見つけた「停滞解除を裏付けられず元の判断に戻る際、関係評価を落としていた」「物理的な効果が同じなら、関係上の価値が違っても高費用の候補を削っていた」という接続不良を修正した。新しい感情を追加せず、既に知っている相手への態度を候補の除外・復帰・読み・補完・学習案の比較にも渡す。これは賢さ全般を解決する改修とは分ける。

## 協力する能力と、協力を選ぶ条件

目標は、状況と本人の目的に照らして協力が有効なら、その機会を見つけ、相手に働きかけ、成立する手順を作れること。全員が常に協力することや、働きかけが必ず成功することは要求しない。ゲーム側の手段と情報の範囲で、単独行動、協力、拒否、条件の修正、撤退を比べる。性格・主義・欲求・信頼・負担・代案によって選択が違ってよい。

検証では、協力が本人の目的に有効な場面、単独で十分な場面、搾取や過大な負担がある場面、途中で利害が変わる場面を含める。機会を理解できず手順を作れない能力不足、理解したうえで本人の軸に沿って選ばない判断、妥当な働きかけをしても相手の拒否や不確実性で成立しなかった結果を分ける。協力率や全員生存だけを合格基準にせず、不成立をすべて人格のせいにして能力不足を隠すこともしない。[任意の接続契約](VOLUNTARY_COOPERATION.md) はこの基準の一部を検証したもので、自律的な協力形成全般の完成ではない。

## 次の改修の優先順位と合否

2026-10-16の優先順位変更：自発的な協力は現在の実装・証拠でいったん区切る。契約、拘束、長期連合、再同意の予測を次の中心にしない。既存の任意経路は残すが、協力特有の機能追加より、単独行動・対戦・資源管理に共通する判断品質を優先する。

**第一は、学ぶ本人を含めた将来評価の安定。** `owned_rollout` で、実行と同じ `DecisionLoop` の経験・予測・欲求・進展を未来の分岐へ複製し、目的点とそこへ至る嗜好の経路を接続する。実観測の後は更新済み本人から読み直す。実行と予測で同じ公開結果を与えた時の更新一致と、未知の結果を当てる予測品質は別に測る。[接続契約](OWNED_VALUE.md)、[持続世界での検証](../evidence/owned_value/REPORT.md)。

世界を生成する法則と、想像の中で学ぶ本人を分ける。本人の見込みが変わっただけで世界法則まで変える近似は採らない。将来の目的点だけを足して欲求・価値・費用の流れを省略する方式も、この接続では使わない。一方、将来の毎手で外側の探索を無制限に繰り返すことは省き、必要なら回数を明示して再計画する。途中評価を終局の実結果や校正済み勝率と呼ばない。

検証の中心は、同じ人物・情報・乱数・ルールでの長い実行。資源・負傷・設備・経験を初期化しない128ターンの競り、資源管理、戦闘、賭けで、即時判断、短い流れの評価、本人を含む将来評価を比較する。既知の入札反例は別の独立試走で検査する。一つの成功例や内部状態の一致だけを完成としない。

2026-10-17の競り回復検証では、未知の応答分布と変化点を扱う区間予測器を追加した。予測開始時の履歴・生成仮定を固定し、未来の公開応答列に条件づける任意の世界継続を接続する。現在の平均確率を毎手独立に使う近似と、将来の本人が学ぶ利益を区別できる。公開応答の学習イベントが欠ける接続は拒否する。固定人格・通常Policyは維持する。

続く接続比較では、毎回の再計画だけでは戦闘が悪化した。未来の本人を即時判断だけに限る近似が、準備後に立て直す能力を過小評価していた。実観測後の再計画と、予測中の同じ本人による必要時の二手評価を合わせた構成を固定し、独立確認560実行・ストレス40実行を完了した。全4ルール×4対照の平均目的得点と各人格の平均が改善し、品質を優先する任意構成として採用した。全ゲームの既定値は変更しない。[全結果・採用範囲・悪化の診断](../evidence/owner_continuity/REPORT.md)。予測改善だけでは判断改善にならなかった前段は [auction_recovery](../evidence/auction_recovery/REPORT.md) に保存する。

残る中心は、**評価窓より後の利益を見落とすことと、予測・標本の不確かさを候補差へ正しく反映すること**。人格×傾向の4群には観測平均の損が残り、資源投資には評価期間を伸ばすと選択が変わる反例がある。競りの真の収支分解と本人の候補全体の比較により、偶然性・人格の支払い・評価の不足を区別している。事後の指標で実得点の悪化を消さず、負けた人格の係数を少しずつ調整する循環にも戻らない。学習した継続価値や深さの選択を試す場合は、人格を含む同一の将来方策と情報条件へ接続し、新たな独立長期比較で判断する。遅れて届く目的誤差を直接学習する汎用評価器は未完成。

比較の出発点となった旧証拠は [frontier_value](../evidence/frontier_value/REPORT.md)、[preference_basis](../evidence/preference_basis/REPORT.md)、[adaptive_opportunities](../evidence/adaptive_opportunities/REPORT.md)、[prediction_recovery](../evidence/prediction_recovery/REPORT.md)。新しい検証は一つの持続世界で行い、旧来の短試合反復を同じ長期実績として足さない。条件の凍結、未使用乱数、事後の反例診断を区別する。

**第二は、本人の全更新を通す接続の維持。** 欲求・関係・進展監視・相手予測が通常、計画採用、辞退、復帰、保存復元、モデル内の本人で途切れないようにする。効果・応答・目的・関係の欠測を分け、想像した経験を実経験へ混ぜない。実結果から改訂する対象が即時効果、相手の反応、宣言した時点の目的値のどれかを揃える。[共通実行契約](DECISION_LOOP.md)、[旧接続監査](../evidence/lifecycle_integration/REPORT.md)。

個々の部品が使えることと、任意の組合せの品質は別。外部reader、value proposal、回復の証拠要求を無条件に重ねない。保存した全状態の再生、同じ行動・観測からの更新、長期実得点を照合してから接続範囲を広げる。単一の「全部入り」設定をまだ認定しない。

**第三は、人格の伝わる展開。** 上の基盤を保ったうえで、警戒しても関係を完全に切らない、今は譲って回収する、仲間の利害を踏まえて役割を変える、といった場面を通しで観測する。専用の台本や意味のない失敗で面白さを足さない。

採否は、事前に固定した異なるルール・途中局面・人格で、目的の利益と損、主義のための支払い、停滞、情報の公平性を報告して決める。既に全勝の条件、同じ決定論的軌跡の再実行、同じ世界の複数NPCを独立標本として水増ししない。速度費用は当面の合否に使わない。全般的な賢さ、人間水準、面白さの完成は未達成。

未知の公開応答分布を学ぶこと、未知の知覚特徴やルールを発見すること、人格の好みを替えて経験を転用することは別の能力。残資源の有限グラフや固定欲求の検証結果を、動く全心理状態・無期限の世界へ自動的に一般化しない。

## 主要な根拠と接続契約
