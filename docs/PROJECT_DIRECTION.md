# 目指す人格NPCと次の検証

目標は、ゲーム内で自分の目的とこだわりを持って暮らす人間の役割を演じるNPC。以下は開発の判断基準であり、達成済みの能力の宣言ではない。勝率の均等化や、相手への対策そのものを報酬にすることは目指さない。

人格らしさの評価と弱点の補填は開発側が引き受ける。人間へ細かい数値や軌跡の鑑定を丸投げしない。人間は目的と感触を伝え、開発側は人間の行動パターンとの整合、本人の合理性、状況と経験への対応を具体的な実行から判断して報告する。今回の相手別の関係評価の接続と得失は [social_appraisal](../evidence/social_appraisal/REPORT.md) を正本とする。

## 七つの基準

1. **人格と価値の一貫性**：固定の性格・主義を、場面や勝敗だけで書き換えない。欲求・意図・経験と分離する。現在の契約検査は固定軸を守るが、人間らしい長期的一貫性を実証したものではない。
2. **動く欲求と経験**：観測した不足や経験で判断が変わる。即時結果と将来の予測を混ぜず、欠測を失敗として学習しない。実装は有限記憶と工学的な更新則で、心理モデルの科学的校正は未完成。
3. **公平な先読みと相手への適応**：同じルールと本人が知れる情報から考え、非公開の現在手・未来イベント・実乱数を参照しない。有限の相手仮説と任意の先読みはあるが、戦闘の相手モデルの学習や汎用的な読み合いは未完成。
4. **効く手段を使い、失敗から修正する**：働いている方策は不要に捨てず、失敗反復・状況変化・予測誤りを区別する。単発の不運や、別の継続を実行した後の負けだけで仮説を撤回しない。条件別の即時経験はあるが、遅延成果の信用割当は未接続。
5. **多数の独立した個体と反射速度**：人格・記憶・エピソードを混ぜない。高価な読みを常時必須にせず、通常判断を数値バッチで処理する。独立小戦場の計測はあるが、大量NPCの実時間ゲーム全処理を達成したとは言えない。
6. **ゲームをまたぐ再利用**：人格判断と学習の境界を共通にし、ルール・合法手・観測・目的尺度はadapterへ置く。複数の自作ゲームへ接続済みだが、未知の商用ゲームへ自動で正しい評価器を作る機構ではない。
7. **対戦相手・世界の住人としての面白さ**：判断の癖が伝わり、相手を読む手掛かりになり、利害の衝突・協力・妥協から展開が生まれるかを評価する。単に強い、変わった手を選ぶ、心理状態が細かいだけでは達成扱いしない。現在の数値比較は、この面白さを実証したものではない。

人間らしさはゲーム体験のために誇張・省略する。有限の性格・欲求・主義から生じる執着、危険への姿勢、義理などは、選択とその後の対応から人物の特徴が伝わる程度に強調してよい。判断や展開に効かない心理の細部は省く。癖は読めるが、経験や状況の変化で手段を変え、同じ攻略で永久にはめ続けられない人物を目指す。合理性の土台、固定軸、公平な情報、個体ごとの独立性は保つ。面白さを理由に恣意的な失敗、無根拠な乱択、特定ゲーム名への分岐、筋書き通りの結末を足さない。

実行例の評価では「どの癖が見えたか」「その癖がどんな葛藤や展開を生んだか」「状況が変わった時に判断の筋を保って対応したか」を開発側が説明する。勝率・人格間の行動差と、対戦や世界の面白さは区別し、測れていない楽しさを達成済みと報告しない。

## 今の判断

`recovery-options` の追加候補は192対で改善0・悪化1・同じ191、途中評価は改善9・悪化9・同じ174だった。任意の実験として残し、既定の判断には有効化しない。[比較結果](../evidence/recovery_options/REPORT.md)を参照。

次の小さな一歩は、予測した本人の継続と相手の行動を、実行されたものと分けて記録すること。公開状態が同じ時の行動不一致、状態自体のずれ、終局、欠測を区別する。これは誤った学習を避けるための診断であり、知性や勝率の改善ではない。

## 次の採否ゲート

- 予測・実行・目的尺度・時間単位・所有者が対応しているか確認する
- 本人の再判断による継続変更と、相手仮説の不一致を別々に測る
- 同じ状態・同じ手でも結果が違う場合、偶然やモデルのどれが原因かを未検証のまま断定しない
- 遅延学習を接続する前に、更新前の予測、支持範囲、欠測、標本依存、採用後の判断利益、撤回条件を定める。未実行経路や一つの一致標本から他の手の信頼を上げない
- 改善案は固定人格・公開情報・個体分離を保った対条件比較で判断し、得失と失敗条件を報告する
- 新しいゲーム接続と性能改善は別々に測り、診断の成功を実時間性能や汎化の証明にしない

外部の考え方を参考にする時は一次資料と利用条件を確認し、概念への類似、実装への導入、実験で確認した能力を区別する。[既存の取り組みとの関係](RELATED_WORK.md)を参照。

## 自己継続の近似で分かった限界

人格の主義階層と近接得点帯に目的戦術を制限する候補を、統合main上で32対の留保条件と既知seed180に比較した。自己継続不一致は306/404→302/366、勝利20→19で、growthの勝利とsteadyの停滞にも悪化があった。移動失敗57→20は改善だが、全面採用しない。[条件・得失・費用](../evidence/persona_continuation/REPORT.md)。

一段の完全再計画より軽いことと、実際の本人の判断に近いことは別に検証する。次はまず、移動失敗の減少が根の組合せや衝突回避だけでも再現するかを、従来のobjective自己継続を維持した別の比較で調べる。因果関係は未確認で、現在の結果をレビュー・公開するまでは新実験を開始しない。「未来も先読みする本人」の小さな近似も課題として残る。主義の書換えや勝率補正で帳尻を合わせず、自己一致・目的利益・停滞・費用を同時に見る。


## 根の衝突補完を切り出した結果

PR3公開後、従来のobjective自己継続を固定し、共同planner辞退後の味方の根だけを既存tier・近接帯・progress/waste制約内で補完するdefault-off部品を比較した。旧標本の12衝突tick中11では、非衝突個体を変えずに代案があった。proof不成立で旧停止を保持する許可を、新たな期限切れ停止を導入する許可に広げない境界も追加した。

新しく固定した32対では味方衝突が一度も起きず、介入0、全実軌跡一致、21勝ずつだった。これは利益の再現や無害性の証明にならない。好都合なseedに差し替えず、曝露不足を明示して既定への昇格を保留する。[機構・条件・費用](../evidence/root_collision/REPORT.md)。次の確認設計を行うなら、独立に事前定義した混雑条件を用い、目的達成・人格・停滞・費用も同時に見る。

## 混雑条件を固定した対照試験

3種の混雑配置48対と通常開始16対で、既存の根補完を変えずに比較した。局所衝突と全体勝利は改善したが、自然な対照曝露は8tick・4局で事前の12tick・6局に届かず、steadyの目的進捗と留保careの停滞も悪化した。混合配置に合法な競合機会はあっても、実際の味方＋敵同時競合は0件だった。既定offを維持し、新しい譲歩アルゴリズムは追加しない。[曝露・敵予測・行き先を分けた結果](../evidence/controlled_congestion/REPORT.md)。

9回の根補完は同一状態の事後規則再生で直後の失敗18件を0にしたが、その後の再判断まで良くする保証にはならない。敵仮説のmissと目的・経験・停滞を別々に追い、移動層だけで「人間として暮らす役割」を代用しない。


## 計画の保持と、人格に沿う選び直しの区別

共有列探索の後、前の計画を現在の観測から再評価する有限の意図を追加した。全モデル分岐に共通する残りの列だけを保持し、同じ目的を遅く達成する新案との比較に戻す。現在の最大主義tierや進捗の制限を越えて継続を強制しない。固定比較と採否は[continuity_transfer](../evidence/continuity_transfer/REPORT.md)を正本とする。

資源管理の既知の失敗には、保持していた達成案が現在の主義tierから落ちる局面があった。計画忘却だけで説明せず、主義の累積利益、終局までの時間、目的達成を同じ期間でどう評価するかを区別する必要がある。人格に沿った意図的な損と、評価方式が生む不要な先送りはまだ識別できていない。主義を無視して勝利を優先すれば直ったとは扱わない。新しい機能や報酬項を増やす前に、この境界を共通の比較で検証する。


## 絶対優先の見直しによる改善

保持の追加だけでは解けなかった失敗に対し、少差の主義利益が目的・欲求・費用の任意の大差を拒否する前処理を外し、既存の有限な重みで比較する別方向を実装した。主義の数値を弱めず、同じ方策を実反射とモデル継続へ接続する。以前の探索未達を9手の達成へ改善し、別条件の資源管理でも達成が増えた。得失の正本は[finite_transfer](../evidence/finite_transfer/REPORT.md)。

戦闘では勝ちを狙うリスクが増え、生存引き分けが相打ちになった例もある。新たな全面採用gateは通っていない。次は主義の拒否を戻すのでなく、ゲーム目標・生命/資源の損失・少数モデル標本の不確かさを分け、本人にとって利益のあるリスクと見込み違いを判別すること。物流の準備列発見は別の残る課題。新候補が全ゲームの賢さを成立させたとは扱わない。

## 異なる探し方と同じ人格の組み合わせ

人格の評価を固定したまま、ビーム探索と合法行動列のサンプリングを接続した。前者が途中で落とす準備・妥協の列を、後者が最後まで試せる構造にする。個体のこだわりを検索手法へ埋め込まず、候補を発見してから共通の主観評価へ返す。通常反射・相手仮説・経験更新の境界は維持し、期間・深さ・幅・試行数をゲーム側が制御する。

組み合わせた方が常に賢いとはしない。固定した3方式の実績・追加費用・失敗は [hybrid_transfer](../evidence/hybrid_transfer/REPORT.md) を正本とする。モデルが正しくても短い期間や本人の利害で未達になり得る。次の改善も、評価と探索と実行のどこが不足したかを分けて判断する。
